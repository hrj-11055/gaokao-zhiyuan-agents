## 一、用户画像：你的用户到底是谁？

高考志愿填报产品的核心用户有**两类**，需要完全不同的策略：

### 1. 家长（主要付费用户）

- **年龄**：40-55 岁，有一定消费能力
- **痛点**：怕孩子选错专业、浪费分数、不了解就业前景
- **信息渠道**：微信朋友圈/群、小红书、抖音、快手
- **决策特点**：看重"权威感"和"干货"，愿意为确定性付费
- **触发时机**：高考出分前后（6 月中-7 月底）是黄金窗口

### 2. 考生（使用者，部分也会付费）

- **年龄**：17-19 岁
- **痛点**：迷茫、不知道自己适合什么、不想听爸妈瞎指挥
- **信息渠道**：小红书、B站、抖音、同学推荐
- **决策特点**：更在意"好不好玩""有没有个性""同龄人在用什么"
- **触发时机**：考完试到填志愿期间

### 营销策略原则

> **对家长卖"确定性"：数据、报告、专业分析**
> **对孩子卖"掌控感"：AI 帮你做主、自己选自己的路**

## 二、获客渠道与执行计划

### 渠道 1：小红书（核心阵地）

**为什么选小红书？**
- 家长用户（尤其是妈妈）高度活跃
- 搜索属性强——家长会主动搜"高考志愿怎么填"
- 图文内容制作门槛低，适合 AI 辅助批量生产
- 长尾流量好，一篇爆款可以持续带来流量

#### 内容策略（4 种内容类型轮换）

| 类型 | 频率 | 示例 | 目的 |
|------|------|------|------|
| **情报干货** | 每日 1 篇 | "2026 年这 5 个专业已经饱和，千万别踩坑" | 吸引搜索流量，建立专业形象 |
| **数据报告截图** | 每 2 天 1 篇 | 展示专业测评报告/大学深度报告截图 | 展示产品价值，引发好奇 |
| **使用教程** | 每周 2 篇 | "手把手教你用 AI 填志愿，3 分钟出方案" | 降低使用门槛 |
| **用户故事** | 每周 1 篇 | "广东 580 分如何精准锁定 211" | 社会证明，激发从众心理 |

#### 小红书内容模板

```
标题公式（选一个）：
- 数字 + 痛点："580 分能上什么学校？这张表告诉你"
- 反常识 + 好奇："这个专业 90% 的人都报错了"
- 身份 + 场景："高三家长的焦虑，我用这个工具解决了"

内容结构（所有内容统一引导到小程序）：
1. 钩子（前 2 行）：抛出一个让家长焦虑/好奇的问题
2. 价值（中间）：给出具体数据或分析（直接用产品生成的报告截图）
3. 变现引导（关键！）：统一话术引导到小程序
   - "完整报告在微信搜小程序「峰哥咨询参考」，AI 帮你分析"
   - "198 元志愿填报资料包，进小程序免费领"
   - "想知道你家孩子能上什么学校？去小程序试试 AI 志愿分析"
4. 标签：#高考志愿 #志愿填报 #高考 #选专业 #大学
```

#### AI 批量生产流程

1. 你提供选题方向（如"法学类专业避坑"）
2. 用 DeepSeek/GPT 生成 5-10 篇初稿
3. 人工润色，加入个人语气和真实数据
4. 配图用产品截图 + Canva 简单排版
5. 定时发布（建议时间：早 7-8 点、午 12-13 点、晚 20-21 点）

**为什么做快手？**
- 二三线城市家长用户集中
- 竞争比抖音小（志愿填报赛道在快手还没饱和）
- 视频内容可以做得更接地气

- 口播为主，真人出镜效果最好（可以不出镜，用图文+配音）

- 标题要有"话唠感"："各位家长注意了啊！"

**更新频率：** 每天 1 条短视频（AI 生成文案 + 简单配图/录屏）

## 四、小程序内的变现机制

> 所有的营销动作把人拉进来了，接下来全靠产品内设计来赚钱。

### 4.1 免费层（获客 + 体验）

| 功能 | 免费额度 | 目的 |
|------|---------|------|
| AI 对话 | 前 3 次免费 | 让用户体验"AI 帮我填志愿"的价值 |
| 198 元资料包 | 关注即领 | 获客钩子 |
| 专业/院校基础信息 | 免费 | 展示数据量，建立信任 |

### 4.2 付费层（会员 19.9 元/月）

| 功能 | 会员权益 | 卖点话术 |
|------|---------|---------|
| AI 无限对话 | 不限次数 | "志愿填报是一辈子的决定，别在 19.9 上犹豫" |
| 专业深度报告 PDF | 每月 N 次下载 | "840 个专业完整分析报告，帮你避开天坑" |
| 院校深度报告 PDF | 每月 N 次下载 | "目标院校真实情况，比招生简章管用 100 倍" |
| 综合志愿报告 | 不限次数生成 | "AI 根据你的分数、性格、兴趣，生成专属方案" |

### 4.3 付费触发时机（关键设计）

用户什么时候最可能掏钱？

1. **AI 对话 3 次用完** → "还想继续问？开通会员解锁无限对话"
2. **查看专业报告，只看到 30%** → "完整报告含就业数据、薪资分析、院校推荐，会员专享"
3. **生成综合报告时** → "生成你的专属志愿方案，仅需 19.9 元/月"
4. **直播间氛围** → "今天直播间限时优惠，原价 198 现价 19.9"

### 4.4 针对家长的变现（确定性 + 数据）

- 外部内容展示报告截图 → 只露 30%，标注"完整版在小程序"
- 报告中的数据要有冲击力（就业率、薪资、录取分数线）
- 家长最愿意为什么付费？**"帮孩子避坑"** — 报告里突出"专业红黑榜"

### 4.5 针对考生的变现（掌控感 + AI）

- 强调"AI 帮你分析，不用听爸妈瞎指挥"
- MBTI/Holland 测评作为免费入口 → 结果引导"匹配你的专业推荐，会员看完整版"
- 生成综合报告 = "你专属的志愿方案" → 个性化体验

### 4.6 分享裂变（降低获客成本）

- 生成报告后支持"分享给好友"
- 分享者获得额外解锁次数
- "帮孩子选志愿，分享给其他家长一起看看"
- 裂变话术："你家孩子考了多少分？我用了这个 AI 工具分析，挺好的，推荐你试试"

## 五、自媒体营销基础知识科普

### 5.1 核心概念

| 概念 | 通俗解释 |
|------|---------|
| **私域流量** | 你自己能随时触达的用户（微信群、公众号粉丝、小程序用户） |
| **公域流量** | 平台上的流量（小红书推荐、抖音推荐），你无法直接控制 |
| **转化漏斗** | 看到内容 → 点击 → 进入小程序 → 注册 → 付费。每一步都有流失 |
| **AARRR 模型** | 获客(Acquisition) → 激活(Activation) → 留存(Retention) → 变现(Revenue) → 推荐(Referral) |
| **ROI** | 投入产出比。花 100 块带来 300 块收入，ROI = 3 |
| **KOL/KOC** | KOL = 大V（粉丝多），KOC = 素人（粉丝少但信任度高） |

### 5.2 内容营销的"三阶段"模型

```
阶段 1：冷启动期（第 1-2 周）
├── 目标：测试内容方向，找到能跑通的内容类型
├── 方法：每天发 3-5 条不同类型的内容
├── 指标：看哪类内容的点赞/收藏/评论最高
└── 重点：不需要粉丝量，只需要找到"内容-受众"的匹配

阶段 2：增长期（第 3-4 周）
├── 目标：放大有效内容类型，开始稳定获客
├── 方法：复制高互动内容模式，增加发布频率
├── 指标：每日新增小程序用户数
└── 重点：建立内容生产 SOP，用 AI 提效

阶段 3：变现期（第 5 周起）
├── 目标：优化转化，提高付费率
├── 方法：AB 测试不同的引导话术、福利设计
├── 指标：注册→付费转化率、客单价、复购率
└── 重点：用户体验闭环，减少流失
```

### 5.3 小红书 SEO（让家长搜到你）

家长会搜这些关键词（你的内容要覆盖）：

**高搜索量关键词：**
- 高考志愿填报
- 志愿填报指南
- XX 分能上什么大学
- XX 专业就业前景
- 选专业避坑
- 张雪峰说 XX 专业
- 2026 高考志愿

**长尾关键词（竞争小但精准）：**
- 广东 580 分能上什么学校
- 计算机科学与技术就业方向
- 女生适合学什么专业
- 理工科专业推荐
- 高考志愿填报常见错误

### 5.4 快手运营要点

- **黄金 3 秒**：视频开头必须有"钩子"（"家长们注意了！"）
- **完播率**：快手算法看完播率，内容要紧凑
- **互动**：引导评论（"你们家孩子考了多少分？打在评论区"）
- **稳定更新**：算法偏好稳定产出的创作者

### 5.5 直播带货/转化要点

- **不要一直卖**：80% 时间给干货，20% 时间介绍产品
- **制造紧迫感**："今天直播间专属价""只有今天有这个福利"
- **互动为王**：回答问题 = 展示专业度 = 建立信任 = 转化
- **数据说话**：展示真实用户的使用效果，比空口说好用 100 倍

## 九、风险与注意事项

1. **合规风险**：不承诺录取结果，不贩卖焦虑（教育部已发文规范）
2. **内容同质化**：志愿填报赛道内容多，要有差异化（AI 分析 = 你的差异化）
3. **季节性**：志愿填报是强季节性产品（5-7 月高峰），其他时间需要持续经营内容
4. **黑粉/差评**：提前准备应对话术，不争论，用数据回应
5. **平台规则**：了解各平台的引流规则，避免被封号（小红书对外链管控严格）
