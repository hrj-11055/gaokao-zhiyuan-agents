# Tab Bar Icons

此目录存放底部 Tab Bar 导航图标。

## 图标规格

- **尺寸**: 64x64 像素（推荐）
- **格式**: PNG
- **模式**: 透明背景，单色图标

## 需要的图标

| 图标文件 | 说明 | 颜色建议 |
|---------|------|---------|
| `home.png` | 首页（未选中） | #9CA3AF (灰色) |
| `home-active.png` | 首页（选中） | #F97316 (橙色) |
| `assess.png` | 测评（未选中） | #9CA3AF (灰色) |
| `assess-active.png` | 测评（选中） | #F97316 (橙色) |
| `profile.png` | 我的（未选中） | #9CA3AF (灰色) |
| `profile-active.png` | 我的（选中） | #F97316 (橙色) |

## 设计建议

- 首页图标：房子/主页图标
- 测评图标：文档/问卷/笔图标
- 我的图标：用户/个人图标

## 替换说明

当前使用占位图标，请将设计好的图标文件放入此目录并替换同名文件。
