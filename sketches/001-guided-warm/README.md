## Variant: 温暖引导式

### Design stance
每屏只有一个主行动点，用温暖视觉降低高考志愿场景的焦虑感。

### Key choices
- Layout: 单卡片聚焦，步骤进度条引导
- Typography: 24px 大标题 / 14px 副标题 / 13px 正文
- Color: 温暖橙 #F97316 + 柔和蓝 #93C5FD
- Interaction: 点击步骤切换面板状态

### Trade-offs
- Strong at: 新用户引导、降低焦虑、高完成率
- Weak at: 信息密度低，回头用户可能觉得步骤多

### Best for
- 首次使用的焦虑型家长和考生
- 不熟悉小程序操作的用户
