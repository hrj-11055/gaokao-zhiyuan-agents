## Variant: 对话优先式

### Design stance
首页就是 AI 对话，让用户自然地通过聊天完成信息收集和咨询。

### Key choices
- Layout: 全屏对话界面 + 浮动测评入口
- Typography: 15px 对话文本 / 13px 按钮
- Color: 橙色气泡 + 极简灰背景
- Interaction: 输入发送消息、标签展开编辑

### Trade-offs
- Strong at: 自然流畅、年轻人喜欢、交互直观
- Weak at: 可能缺乏「正式感」、AI 引导质量要求高

### Best for
- 熟悉 ChatGPT / 微信聊天的年轻用户
- 不喜欢填表单的用户
