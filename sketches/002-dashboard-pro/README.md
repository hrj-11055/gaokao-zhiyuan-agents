## Variant: 仪表盘专业式

### Design stance
像一个精心设计的控制中心，数据一目了然，适合理性决策型用户。

### Key choices
- Layout: 环形进度图 + 2×2 快捷操作网格
- Typography: 28px 数字强调 / 16px 标题 / 13px 正文
- Color: 深蓝 #2563EB（专业）+ 橙色 #F97316（行动）
- Interaction: 点击环形图切换进度状态

### Trade-offs
- Strong at: 信息密度高、专业感强、回头用户友好
- Weak at: 新用户可能信息过载、视觉复杂度高

### Best for
- 理性决策型用户
- 已完成初步信息填写的回头用户
