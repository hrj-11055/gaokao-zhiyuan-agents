## 失败原因分析

两次爬取的失败原因一致：**claude CLI 调用超时或返回 exit code 1**。根本原因是以下两类：

1. **超冷门小语种**：网上几乎没有该专业的中文资料（就业数据、院校排名、行业前景等），LLM 搜索 4 轮后仍无法收集足够数据，生成内容过短或直接失败
2. **热门专业反而在第一轮批量失败**：新闻学、广告学、英语、商务英语等。原因是第一轮超时设置为 600 秒，这些专业搜索量大、生成内容长，容易超时。第二轮已延长到 1800 秒但仍未重试这些（第一轮已标记失败但第二轮 `--retry` 只看文件大小 < 1000B 的）
