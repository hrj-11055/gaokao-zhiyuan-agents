# 高考志愿填报行业 - 市场调研与竞品分析提示词

> 用于配合 `everything-claude-code:market-research` 或 `everything-claude-code:deep-research` skill 使用

## 调研背景

我们正在开发一款"张雪峰风格"的高考志愿填报智能体产品，技术架构为 Dify（AI Agent 平台）+ 微信小程序前端。产品定位为"工具为主 + 智能体为辅"，核心差异化在于用 AI 模拟张雪峰的咨询风格，提供个性化、有态度的志愿填报建议。

需要通过市场调研和竞品分析，验证产品定位、找到差异化切入点、制定定价策略。

## 调研目标

1. 了解高考志愿填报市场的规模、增长趋势和用户画像
2. 分析主要竞品的产品形态、功能特点、定价策略和用户口碑
3. 识别市场空白和差异化机会
4. 评估 AI 智能体在该赛道的技术可行性和用户接受度

## 调研范围

### 一、市场规模与趋势

- 中国高考人数趋势（近 5 年及预测）
- 志愿填报服务市场规模（付费咨询、志愿卡、APP 会员等）
- 家长和考生在志愿填报上的付费意愿和平均消费金额
- 新高考改革对志愿填报市场的影响（选科组合增多 → 决策更复杂 → 需求增长）
- AI/大模型技术对志愿填报行业的冲击和机会

### 二、竞品分析（按产品形态分类）

#### 传统数据工具类

| 竞品 | 调研重点 |
|------|---------|
| 掌上高考（升学在线） | 数据覆盖范围、产品功能、定价、用户量 |
| 夸克高考 | 阿里系产品优势、AI 推荐功能、用户获取路径 |
| 高考志愿填报卡（各品牌） | 卡片模式定价、渠道（学校/书店/线上）、利润空间 |
| 百度高考 | 搜索入口优势、AI 功能、数据来源 |
| 腾讯教育高考频道 | 微信生态内的产品形态 |

#### 人工咨询类

| 竞品 | 调研重点 |
|------|---------|
| 张雪峰团队（峰学蔚来） | 服务定价（万元级）、服务流程、目标用户、营收规模 |
| 百家讲坛式高考讲座 | 线下讲座模式、覆盖范围、定价 |
| 学校老师/班主任指导 | 免费、影响范围有限但有信任基础 |
| 各类高考志愿填报师 | 个人IP模式、定价、服务质量参差 |

#### AI 智能体/对话类

| 竞品 | 调研重点 |
|------|---------|
| 各类套壳 ChatGPT 志愿助手 | 产品形态、用户评价、数据准确性问题 |
| Dify/Coze 上已有的志愿填报 Agent | 功能范围、提示词设计、知识库结构 |
| 大厂 AI 产品中的高考场景 | 文心一言、通义千问、Kimi 等是否已有相关功能 |

### 三、用户画像与痛点

目标用户分为两类：

**高考生（18 岁）**
- 信息获取渠道（抖音/B站/小红书/知乎/学校）
- 对 AI 产品的接受度
- 自主决策 vs 家长主导的比例
- 付费能力

**家长（40-50 岁）**
- 焦虑程度和付费意愿
- 信息获取渠道（微信/短视频/朋友推荐）
- 对"张雪峰"IP 的认知和信任度
- 对 AI 产品 vs 人工咨询的偏好

**核心痛点验证：**
- 信息不对称到底有多严重？
- 现有工具（掌上高考/夸克）是否已经解决了数据问题？
- 用户真正缺的是"数据"还是"建议"？
- "张雪峰风格"（有态度、直接）是否是真正的差异化？

### 四、商业模式分析

| 模式 | 代表产品 | 定价区间 | 优劣势 |
|------|---------|---------|--------|
| 免费工具 + 广告 | 掌上高考、夸克 | 免费 | 流量大但变现难 |
| 付费志愿卡 | 各品牌 | ¥100-500 | 传统模式，利润好但同质化 |
| 一对一咨询 | 张雪峰团队 | ¥5,000-30,000 | 高客单价但无法规模化 |
| AI 对话免费 + 报告付费 | 我们的模式 | 免费 / ¥50-200 | 待验证 |
| 订阅制 | 少数产品 | ¥30-100/月 | 持续性收入但高考场景低频 |

### 五、技术趋势

- 大模型在志愿填报场景的应用现状
- 知识库/RAG 技术在高考数据场景的实践
- 多模态（语音/图像）在志愿填报的可能性
- 微信小程序 + AI Agent 的技术可行性和审核要求

## 输出要求

请按以下结构输出调研报告：

1. **市场概况**：市场规模、增长趋势、关键数据
2. **竞品矩阵**：按产品形态分类，对比功能/定价/用户量/差异化
3. **用户洞察**：两类用户的核心需求和付费意愿
4. **机会分析**：市场空白、差异化切入点、我们的竞争优势
5. **风险提示**：市场壁垒、合规风险、技术风险
6. **行动建议**：基于调研结果的 MVP 调整建议

## 调研约束

- 数据时效性：优先使用 2024-2026 年的数据
- 中国市场为主
- 关注可验证的数据来源，避免道听途说
- 竞品分析要包含实际产品体验（如可能）
