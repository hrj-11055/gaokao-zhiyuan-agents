# 首页考生信息填报卡片设计

## 目标

把首页从“入口展示页”调整为“先填写考生信息，再进入智能填报/咨询”的首屏。用户填写一次省份、科目、分数、位次后，首页自动回显，对话请求和后续报告生成都复用同一份本地画像。

## 页面结构

首页保留当前品牌区，但压缩首屏高度，让信息卡片成为第一视觉焦点。

1. 顶部品牌区：Logo、产品名、短副标题。
2. 主卡片：标题为“2026 高考志愿模拟填报”。
3. 卡片字段按固定顺序展示：
   - 省份：下拉选择 31 省。
   - 科目：二选一，物理类 / 历史类。
   - 分数：数字输入，0-750。
   - 位次：数字输入，选填。
4. 主按钮：信息完整时显示“智能填报”，否则点击后提示补全省份、科目、分数。
5. 辅助入口：免费咨询，进入聊天页，并携带已保存考生信息。
6. 底部免责声明沿用现有文案。

## 数据结构

本地保存键名为 `user_profile`，结构如下：

```js
{
  province: '广东',
  category: '物理类',
  score: 600,
  rank: 32000,
  updatedAt: 1710000000000
}
```

`rank` 可为空；`province`、`category`、`score` 是智能填报的必填条件。

## 交互

用户修改任一字段后立即自动保存。页面再次打开时从本地读取并回填。省份和科目用 picker 承载，分数和位次用数字输入。填写不完整时允许保存草稿，但不允许进入智能填报流程。

聊天页发送消息时读取 `userProfile` 并作为 Dify `inputs` 透传。代理不得覆盖为 `{}`。

## 验收

- 首页首屏展示考生信息卡片，字段顺序为省份、科目、分数、位次。
- 科目只允许物理类和历史类。
- 用户填写后自动保存，返回首页自动回显。
- 聊天请求 body 中包含 `inputs`。
- 代理转发给 Dify 的 `inputs` 与前端传入一致。
