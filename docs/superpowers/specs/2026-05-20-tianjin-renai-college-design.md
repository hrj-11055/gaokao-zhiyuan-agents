# 天津仁爱学院深度研究报告设计方案

**报告目标**：生成一篇 8000 字以上、专业、详实的大学评估报告。
**研究对象**：天津仁爱学院（原天津大学仁爱学院）
**核心结构**：遵循“Citadel 计划”8 模块标准。

## 1. 模块规划与字数分配

| 模块 | 内容要点 | 预估字数 |
| :--- | :--- | :--- |
| **模块一：学术实力** | 天大渊源、二级学院深度剖析、师资结构、产教融合、科研平台。 | 1500 |
| **模块二：录取与生源** | 2023-2025 各省分数位次趋势分析、生源结构、省份性价比。 | 1000 |
| **模块三：毕业生出路** | 就业率分析、行业流向、考研深造明细（8% 的含金量）、薪酬水平。 | 1500 |
| **模块四：区位与产业** | 静海团泊新城规划、京津冀协同发展背景、实习基地。 | 800 |
| **模块五：国际化** | 境外深造去向、国际合作办学、交换生项目。 | 600 |
| **模块六：校园生态** | 转专业政策详解、宿舍食堂硬件、学风管理、学生组织。 | 1200 |
| **模块七：风险提示** | 学费压力、地理位置局限、转设后品牌建设挑战、民办性质。 | 800 |
| **模块八：总结评价** | 六维打分、同类院校横向对比（对比珠海科技学院等）、报考建议。 | 800 |

## 2. 深度分析策略

1.  **历史厚度**：详细挖掘其作为“独立学院”时期与天津大学的深度绑定，以及转设后的资源留存情况。
2.  **专业颗粒度**：不只列出王牌专业，要分析其课程设置、与华为/中软等企业的具体合作模式（如精益智造产业学院）。
3.  **数据可视化（文本化）**：通过大量表格展示 2023-2025 的分数对比。
4.  **学生视角**：引入真实的学生评价细节（如“二食堂的红烧面”、“大一晚自习制度”）。
5.  **行业前瞻**：结合天津市“1+3+4”现代工业体系，分析学校专业的市场契合度。

## 3. 执行工具

- **Google Search**: 补齐 2023 年历史数据。
- **Firecrawl**: 抓取官网最新的教学质量报告和就业质量报告全文。
- **Sub-agents**:
    - `academic_agent`: 负责学术实力与师资。
    - `admissions_agent`: 负责各省录取数据。
    - `career_agent`: 负责就业与深造。
    - `campus_agent`: 负责校园生活与风险评价。

## 4. 进度计划

1.  [ ] 完成 4 个维度的子代理调研与初稿生成。
2.  [ ] 整合初稿，进行扩充与逻辑润色。
3.  [ ] 进行六维打分与竞品对比分析。
4.  [ ] 最终校对与格式化输出。
