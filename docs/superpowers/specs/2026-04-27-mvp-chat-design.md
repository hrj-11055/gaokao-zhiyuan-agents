> 日期：2026-04-27 | 状态：待实施
> 产品：峰哥报考参谋（微信小程序）

---

## 1. 概述

### 1.1 范围

MVP 阶段只实现 **首页 + AI 对话页**，不包含测评填表和综合报告模块。

### 1.2 目标

- 用户打开小程序即可与 Dify AI 智能体进行张雪峰风格的志愿填报对话
- SSE 流式输出，打字机效果，体验接近真人聊天
- 对话历史本地持久化，重进可恢复
- 通过 Node 代理保护 Dify API Key

### 1.3 技术选型

| 层 | 方案 | 说明 |
|----|------|------|
| 前端 | UniApp（Vue 3） | 后续可扩展到 H5 |
| 后端 | Node.js Express 代理 | 保护 API Key，转发 SSE |
| AI | Dify 社区版 + DeepSeek | 已部署在 8.135.37.159 |
| 部署 | Nginx HTTPS + Node | 已有备案域名 |

## 3. 技术架构

```
┌─────────────────────────────────────┐
│        UniApp 小程序（前端）          │
│                                     │
│  pages/                             │
│  ├── index/        首页             │
│  └── chat/         对话页           │
│       └── SSE 流式接收 + 打字机渲染  │
└──────────────┬──────────────────────┘
               │ HTTPS
┌──────────────▼──────────────────────┐
│   Node.js 代理（部署在 8.135.37.159）│
│                                     │
│   /api/chat          → 转发到 Dify  │
│   /api/chat/stream   → SSE 转发     │
│   API Key 存在服务端环境变量          │
└──────────────┬──────────────────────┘
               │ HTTP (内网)
┌──────────────▼──────────────────────┐
│   Dify 社区版（同服务器）            │
│   DeepSeek-V3 对话 / R1 推理        │
│   5 个知识库（KB-1 ~ KB-5）          │
└─────────────────────────────────────┘
```

### 3.1 关键设计决策

| 决策 | 说明 |
|------|------|
| API Key 保护 | Node 代理持有 Key，前端永远不接触 |
| SSE 流式 | 代理透传 Dify 的 SSE 响应，前端逐字渲染 |
| conversation_id | 首轮为空，后续从 Dify 响应中取出，实现多轮上下文 |
| 用户标识 | 用微信 openId 作为 Dify 的 user 字段 |
| 对话历史 | 前端 localStorage 存储，不走服务端持久化 |
| Nginx | HTTPS 终端 + 反向代理到 Node 端口 |

### 3.2 Node 代理路由

**POST /api/chat**

- 读取 body 中的 `query`、`conversation_id`、`user`
- 注入 Dify API Key
- 调用 Dify `/v1/chat-messages`（blocking 模式）
- 返回完整响应

**POST /api/chat/stream**

- 同上，但 `response_mode: 'streaming'`
- 直接 pipe SSE 响应给前端
- 前端解析 `event: message` 和 `event: message_end` 事件

**错误处理：**

- Dify 超时（>30s）→ 返回 "AI 思考时间有点长，请稍后再试"
- Dify 异常 → 返回 "服务暂时不可用，请稍后再试"
- 不暴露原始错误信息给前端

## 5. 交互流程

```
用户输入消息
    │
    ├── 首次消息？→ 显示快捷问题气泡（点击后自动填入）
    │
    ▼
前端: 追加用户消息到消息列表 → 显示"AI 正在输入..."
    │
    ▼
API: POST /api/chat/stream { query, conversation_id, user: openId }
    │
    ▼
Node: 注入 API Key → 转发到 Dify → pipe SSE 响应
    │
    ▼
前端: 逐 chunk 解析 SSE → 拼接到 AI 消息 → 打字机效果渲染
    │
    ▼
流结束: 保存 conversation_id → 存入 localStorage 历史记录
    │
    ▼
用户退出/重进: 从 localStorage 恢复历史对话
```
