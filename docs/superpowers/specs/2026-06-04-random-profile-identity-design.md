# “我的”页随机卡通身份设计

## 目标

将“我的”页当前写死的“峰”字头像和“志愿同学”替换为有记忆点的默认身份：

- 昵称格式固定为“性格词的动物”，例如“勇敢的兔子”“浪漫的猫头鹰”。
- 性格词与动物独立随机，不按动物刻板印象绑定，允许有趣的反差组合。
- 动物头像与昵称中的动物保持一致。
- 默认身份首次生成后保存在本地，后续打开页面保持不变；清除本地数据后重新生成。

## 用户体验

用户首次进入“我的”页时，系统从性格词库和动物头像库分别随机选取一项，组合成默认身份。页面展示动物卡通头像、随机昵称及现有用户 ID、VIP 状态和档案信息。

本次不增加头像选择器、昵称编辑器或微信头像授权入口。身份仅作为默认展示身份，不参与高考档案完整性判断，也不发送到报告、Dify 或会员服务。

## 视觉设计

头像库包含 8 个本地轻卡通动物头像：

- 熊猫
- 企鹅
- 水獭
- 狐狸
- 兔子
- 猫头鹰
- 小熊
- 柴犬

所有头像采用统一的正面动物脸、柔和粉彩底色、圆形裁切友好的插画风格。头像资源随小程序打包，不依赖网络。

## 数据设计

新增独立的默认身份存储键 `profile_identity`，只保存稳定的随机结果：

```json
{
  "personality": "勇敢",
  "animal": "rabbit"
}
```

展示时根据动物键从当前头像目录中解析中文动物名和头像路径，并组合昵称。无效、损坏或过期的存储值会重新生成。

默认身份与 `user_profile` 分离，避免随机昵称影响考生资料、报告输入或服务器同步。`clearAllLocalData()` 会同时移除 `profile_identity`。

## 代码边界

- `gaokao-miniprogram/src/utils/profile-identity.js`
  - 管理性格词库、动物头像目录、随机生成、校验和本地持久化。
- `gaokao-miniprogram/src/pages/profile/profile.vue`
  - 获取默认身份并展示头像和昵称。
- `gaokao-miniprogram/src/utils/storage.js`
  - 清除全部本地数据时移除默认身份。
- `gaokao-miniprogram/src/static/avatars/`
  - 保存 8 个本地卡通头像。

## 错误处理

- 本地无身份数据：生成并保存新身份。
- 本地 JSON 损坏、性格词或动物键无效：生成并覆盖为新身份。
- 页面再次显示：读取同一份身份，不重复随机。
- 清除本地数据：删除身份，下次进入时重新生成。

## 测试

- 性格词与动物使用两次独立随机取值。
- 生成的昵称符合“性格词的动物”格式，头像与动物一致。
- 首次读取会保存，后续读取保持同一身份。
- 损坏或无效身份会重新生成。
- 清除全部本地数据会删除 `profile_identity`。
- “我的”页使用本地头像图片和随机昵称，不再包含写死的“峰”和“志愿同学”。
