# 山东农业大学深度研究报告设计方案

## 1. 报告目标
为考生及家长提供关于山东农业大学（SDAU）的全面、深度、客观的评估，字数要求 8000 字以上，涵盖学术、录取、就业、区位、国际化、校园生活及风险提示。

## 2. 报告结构与核心内容

### 第一章：学术实力——“院士摇篮”与新农科领航
- **核心论点**：山东农大不仅是省属重点，更是具有深厚底蕴的“准双一流”。
- **要点**：
    - 第五轮学科评估突破（作物学 A 类）。
    - 院士资源：3位全职，10位校友院士（李振声等）。
    - 科研平台：全国重点实验室（小麦育种）的稀缺性。
    - 学科布局：以农学为核，理工经管多维协同。

### 第二章：录取与生源——位次博弈与高性价比选择
- **核心论点**：分数线相对亲民，但位次稳中有升，是“捡漏”名校资源的优质路径。
- **数据分析**：
    - 2023-2025 山东省内录取位次趋势。
    - 各省（江苏、广东、河南等）投档线对比。
    - 专业组差异：法学、计算机等热门专业的高溢价分析。

### 第三章：毕业生出路——“深造强校”的底色与新农科红利
- **核心论点**：深造率逐年攀升（41%），是省属高校中考研/保研的“高地”。
- **要点**：
    - 保研率分析（15%-20%）。
    - 就业去向：选调生、国企、农业龙头企业（新希望、金锣）。
    - 薪酬数据：省内第9，数字化农业带来的薪资溢价。

### 第四章：区位与产业——泰山下的“校城融合”
- **核心论点**：泰安虽非省会，但在农业产业及文旅产业上有独特优势。
- **分析**：
    - 泰安“人才强市”政策。
    - 校企合作：华为、拼多多、海尔卡奥斯。
    - 实习基地建设：数百个示范基地对就业的支撑。

### 第五章：国际化——农科特色的全球视野
- **核心论点**：中外合作办学是其国际化的重要抓手。
- **要点**：
    - 英国RAU、德国FOM项目深度剖析。
    - “4+0”与“3+1”模式优劣对比。
    - 交换生机会（CSC项目）。

### 第六章：校园生态——“吃饭大学”与自由转专业
- **核心论点**：生活成本低，学生发展自主权大。
- **要点**：
    - 岱宗 vs 泮河校区生活实测。
    - “第二次选择专业”政策：30%接收率的诚意。
    - 宿舍翻新现状与食堂口碑。

### 第七章：风险提示——理性的冷思考
- **要点**：
    - 地理位置劣势（相比济青）。
    - 专业刻板印象带来的社会认知偏差。
    - 农科专业的高考研压力。

### 第八章：总结评价与报考建议
- **六维打分雷达图**（描述）。
- **横向对比**：对比青岛农业大学或山东师范大学。
- **画像匹配**：适合哪些类型的考生？

## 3. 写作风格
- 专业、深度、客观。
- 采用“数据展示+深度解读+专家观点”的模式。
- 确保字数充实，对每一个数据点进行背后的逻辑拆解。

## 4. 验证计划
- 核对 2025 年最新录取位次。
- 确认第五轮学科评估的非官方但可靠的消息。
- 确保 8000 字以上的体量。
