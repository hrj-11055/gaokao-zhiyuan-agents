# 测评模块设计文档

> 日期：2026-05-12 | 状态：已批准 | 版本：1.0

## 一、概述

为小程序新增两个专业测评工具（MBTI 性格测试、霍兰德职业兴趣测试），配合现有的五环问卷，为用户提供完整的个人特质评估体系，并基于测评结果推荐相关专业。

**核心目标**：
- 通过多维度测评帮助用户了解自己
- 将测评结果与专业数据库联动，提供个性化专业推荐
- 为综合报告生成提供更丰富的用户画像数据

---

## 三、测评内容

### 3.1 五环问卷（现有）

| 属性 | 值 |
|------|-----|
| 题目数 | 22 题 |
| 维度 | 学习风格、学业现状、家庭背景、能力特质、职业期望 |
| 状态 | 已完成，保持不变 |

### 3.2 MBTI 性格测试（新增）

| 属性 | 值 |
|------|-----|
| 题目数 | 48 题 |
| 维度 | E/I (外向/内向)、S/N (感觉/直觉)、T/F (思考/情感)、J/P (判断/感知) |
| 每维度题数 | 12 题 |
| 预计用时 | 8 分钟 |
| 结果输出 | 四字母类型（如 INTJ）+ 各维度得分 + 性格描述 |

**题目示例**：
- 当你感到疲惫时，你更倾向于？
  - A. 独处静默恢复 (I)
  - B. 与朋友聊天放松 (E)

### 3.3 霍兰德职业兴趣测试（新增）

| 属性 | 值 |
|------|-----|
| 题目数 | 60 题 |
| 维度 | R(现实型)、I(研究型)、A(艺术型)、S(社会型)、E(企业型)、C(常规型) |
| 每类型题数 | 10 题 |
| 预计用时 | 10 分钟 |
| 结果输出 | 三字母代码（如 RIA）+ 各维度得分 + 职业倾向 |

**题目示例**：
- 我更喜欢：
  - A. 修理电器 (R)
  - B. 研究科学问题 (I)
  - C. 创作艺术作品 (A)

## 四、页面设计

### 4.1 测评 Tab 页

**路径**：`/pages/assessments/assessments`

**功能**：
- 显示三个测评卡片（五环、MBTI、霍兰德）
- 已完成显示徽章和完成时间
- 未完成显示"去测试"按钮
- 已完成显示"查看结果"和"重新测试"按钮

### 4.2 测评页面

**统一结构**：
```
┌─────────────────────────────┐
│  ←  [测评名称]                │
│  ═══════════════ 15/48       │ ← 进度条
├─────────────────────────────┤
│  题目内容                     │
│                             │
│  ○ A. 选项1                  │
│  ○ B. 选项2                  │
│                             │
├─────────────────────────────┤
│        [上一题] [下一题]      │
└─────────────────────────────┘
```

**交互规则**：
- 单选题：选择后自动跳下一题（可关闭自动跳转）
- 支持返回修改上一题
- 进度本地保存，退出后可继续

**路径**：`/pages/profile/profile`

**功能**：
- 查看已生成的综合报告
- 下载/分享报告
- 查看测评记录（完成时间、结果）
- 设置入口（预留）

## 六、数据准备

### 6.1 MBTI 题目来源

- 使用标准的 MBTI 题目库
- 筛选 48 道具有代表性的题目
- 每个维度 12 题，平衡分布

### 6.2 霍兰德题目来源

- 使用标准的霍兰德职业兴趣量表
- 60 题完整版，每类型 10 题

### 6.3 专业标签数据

- 需要在现有专业评估报告中添加 `tags` 字段
- 或者建立独立的标签映射文件
