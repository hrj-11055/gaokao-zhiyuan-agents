# 高考志愿填报助手 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品背景

每年高考结束后，全国约1000万考生面临志愿填报的决策难题。大多数考生和家长缺乏对院校录取规律的了解，填报志愿往往依赖经验、道听途说，导致高分低就或滑档等问题。

### 1.2 产品定位

一款微信小程序形式的高考志愿填报助手，通过数据驱动的智能推荐和专业测评，帮助考生和家长科学、高效地完成志愿填报。

### 1.3 目标

- 降低志愿填报的信息门槛
- 提供"冲/稳/保"三档科学推荐，减少滑档风险
- 通过专业测评帮助考生发现适合自己的专业方向

## 2. 用户画像

### 2.1 高考生

- **特征**：18岁，面临人生第一次重大选择，对专业和院校了解有限
- **痛点**：不知道自己适合什么专业，不了解目标院校的录取概率
- **期望**：快速了解自己能上哪些学校，哪些专业适合自己

### 2.2 家长

- **特征**：关心孩子前途，对院校有一定了解但信息可能过时
- **痛点**：缺乏数据支撑，担心帮孩子选错
- **期望**：获得客观数据支持，辅助孩子做出正确选择

## 3. 用户故事

### 3.1 智能推荐

| 编号 | 用户故事 | 验收标准 |
|------|---------|---------|
| US-01 | 作为考生，我输入省份、分数和科类，系统推荐冲/稳/保三档院校 | 输入完整信息后3秒内返回结果，每档至少显示5所院校 |
| US-02 | 作为考生，我可以输入全省位次获得更精准的推荐 | 当位次填写时，推荐算法以位次为优先排序依据 |
| US-03 | 作为考生，我可以在推荐列表中查看每所院校的历年录取分数线 | 每个院校卡片显示近3年的最低分和最低位次 |
| US-04 | 作为考生，我可以点击院校查看详细信息 | 详情页展示院校介绍、排名、专业组及各专业历年分数线 |
| US-05 | 作为考生，我可以看到新高考的专业组及选科要求 | 新高考省份的推荐精确到专业组，展示选科要求 |
| US-06 | 作为家长，我可以通过院校排名快速判断学校实力 | 院校卡片和详情页均展示软科、校友会等排名 |

### 3.2 专业测评

| 编号 | 用户故事 | 验收标准 |
|------|---------|---------|
| US-07 | 作为考生，我可以通过MBTI测试了解自己的性格类型 | 完成约20题MBTI测试，返回四个维度结果及性格类型解读 |
| US-08 | 作为考生，我可以通过职业兴趣测试了解适合的专业方向 | 完成约20题Holland测试，返回推荐的3-5个专业方向 |
| US-09 | 作为考生，我可以从测评结果直接查看匹配的院校 | 测评结果页提供"查看匹配院校"按钮，跳转推荐结果页并优先展示相关专业院校 |
| US-10 | 作为考生，我可以随时退出测评并保存进度 | 支持中断后继续答题，进度存储在本地 |

## 4. 功能需求

### 4.1 首页

- 展示两个功能入口："智能推荐"和"专业测评"
- 简洁大气的设计，突出核心功能

### 4.2 智能推荐

#### 输入页

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 高考省份 | 下拉选择 | 是 | 全国31个省份 |
| 高考分数 | 数字输入 | 是 | 0-750 |
| 全省位次 | 数字输入 | 否 | 推荐填写，提升推荐精度 |
| 科类 | 下拉选择 | 是 | 根据省份自动适配（文理/物理类历史类） |

#### 结果页

- 三个Tab：冲 / 稳 / 保
- 院校卡片展示：院校名称、类型标签（985/211/双一流）、所在地、近3年分数线/位次
- 按录取概率排序

#### 院校详情页

- 院校基本信息（名称、所在地、类型、简介、排名）
- 历年院校录取分数线表格
- 专业组列表（新高考）或专业列表（老高考）
- 各专业历年录取分数线

### 4.3 专业测评

#### 答题页

- MBTI测试：约20题，四个维度（E/I, S/N, T/F, J/P）
- Holland职业兴趣测试：约20题，六个维度（R/I/A/S/E/C）
- 进度条显示答题进度
- 支持本地缓存答题进度

#### 结果页

- 性格类型及解读（如"INTJ - 建筑师"）
- 推荐专业方向列表（3-5个）
- "查看匹配院校"按钮

## 5. 非功能需求

### 5.1 性能

- 推荐结果加载时间 < 3秒
- 页面切换流畅，无卡顿
- 首屏加载时间 < 2秒

### 5.2 数据

- 覆盖全国约1000所本科院校
- 覆盖近3年（2023-2025）录取数据
- 覆盖全部31个省份的新老高考数据
- 数据每年更新（高考出分后更新当年数据）

### 5.3 兼容性

- 兼容微信最新版本及前2个大版本
- 适配不同屏幕尺寸

### 5.4 可用性

- 无需登录即可使用核心功能
- 操作步骤不超过3步即可获得推荐结果

## 6. 数据需求

院校录取数据需从外部爬取或购买，覆盖：

- 全国主要本科院校（约1000所）
- 近3年各省份录取分数线及位次
- 新高考省份的专业组数据
- 各专业的录取分数线及位次
- 院校排名数据（软科、校友会等）

## 7. 里程碑

| 阶段 | 内容 | 时间 |
|------|------|------|
| MVP | 智能推荐 + 专业测评 | 2026年高考季前 |
| V1.1 | 用户登录 + 收藏 + 高级筛选 | 2026年高考季后 |
| V1.2 | 付费功能 + 志愿表生成 + 导出 | 2026年底 |

## 8. 不在MVP范围内

- 用户登录 / 微信授权
- 院校收藏 / 对比
- 高级筛选（地域、类型、排名等）
- 付费深度分析报告
- 一对一咨询入口
- 院校/专业搜索
- 志愿表生成与导出
