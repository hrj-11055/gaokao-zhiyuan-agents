# 综合志愿报告生成功能设计

> 日期：2026-05-10 | 状态：已确认

## 概述

用户通过填写五环问卷（22 题）+ AI 对话两个数据源，生成一份个人化的综合志愿分析报告（HTML 文件），通过可分享链接发给家长或自己查看。MVP 阶段不做付费，报告完整开放。

## 架构

```
小程序（新增两个页面）
├── pages/questionnaire/  问卷页（22 题，五环框架）
├── pages/report/         报告结果页（显示链接）
└── pages/index/          首页（新增入口卡片）

gaokao-proxy（47.113.125.147，新增）
├── POST /api/report/generate   生成报告接口
└── GET  /reports/:file         nginx 静态托管

Gemini Flash API
└── 输入：profile + 问卷 JSON + Dify 对话记录
    输出：完整 HTML 报告（6 Tab + ECharts 雷达图）
```

## 数据源

两个数据源并行，随时可生成报告，数据越完整报告越准确：

1. **基本信息**（`user_profile`）：省份、科目、分数、位次（现有）
2. **问卷答案**（`questionnaire`）：五环 22 题（新增）
3. **对话历史**：通过 `conversationId` 调 Dify API 拉取

## 问卷结构（22 题）

### 第一环：学习风格与偏好（5 题，单选）
- Q1 学习偏好：先理解原理 / 大量刷题 / 跟着老师
- Q2 遇到难题：反复拆解 / 先跳过 / 找同学讨论
- Q3 记忆方式：逻辑推导 / 反复抄写 / 做题自然记住
- Q4 课堂习惯：紧跟老师 / 自己推演 / 听懂大意课后补
- Q5 高效时段：早晨 / 下午 / 深夜

### 第二环：当前学业与压力（4 题）
- Q6 优势学科（多选）：语数英物化生史地政
- Q7 薄弱学科（多选）：同上
- Q8 主要压力来源（单选）：同学竞争 / 父母期望 / 自我要求 / 备考本身
- Q9 成绩位置（单选）：前10% / 前30% / 中等 / 偏后

### 第三环：家庭背景与期望（4 题）
- Q10 父母职业（单选）：体制内 / 企业职员 / 自营生意 / 其他
- Q11 家庭对专业的期望（多选）：好就业 / 收入高 / 体面稳定 / 尊重兴趣 / 无要求
- Q12 可接受就读城市（单选）：本省优先 / 北上广深 / 不限
- Q13 家庭经济状况（单选）：宽裕 / 小康 / 普通 / 偏紧

### 第四环：学科长板与能力（3 题）
- Q14 最突出的能力（多选，最多3个）：逻辑推理 / 动手实验 / 语言表达 / 创意设计 / 记忆背诵 / 数据分析
- Q15 最感兴趣的领域（多选）：理工技术 / 医学健康 / 人文社科 / 商科管理 / 艺术传媒 / 法律政治
- Q16 最排斥的方向（多选）：纯理论研究 / 大量背诵 / 对人服务 / 户外体力 / 高风险行业

### 第五环：热情与职业期望（6 题）
- Q17 成就感来源（单选）：解出难题 / 帮助他人 / 作品被认可 / 管理协调 / 赚到钱
- Q18 工作最重要的是（单选）：收入高 / 稳定安全 / 有意义 / 自由灵活 / 社会地位
- Q19 工作方式偏好（单选）：独立深度工作 / 团队协作
- Q20 最感兴趣的行业（单选）：互联网科技 / 金融 / 医疗 / 教育 / 制造工程 / 传媒艺术 / 政府公务 / 法律
- Q21 毕业后首选方向（单选）：直接就业 / 国内考研 / 出国留学 / 考公考编 / 未想好
- Q22 工作城市偏好（单选）：回家乡 / 留在读书城市 / 去一线城市 / 无所谓

## 后端接口

### `POST /api/report/generate`

**Request：**
```json
{
  "userId": "user_xxx",
  "profile": { "province": "广东", "category": "物理类", "score": 620, "rank": 32000 },
  "questionnaire": { "q1": "先理解原理", "q6": ["数学", "物理"], ... },
  "conversationId": "dify-conv-id"   // 可为空字符串，未对话过时省略对话记录
}
```

**处理流程：**
1. 限流检查：同一 userId 10 分钟内只允许生成一次
2. 若 `conversationId` 非空，调 Dify `GET /v1/messages` 拉取对话记录（最多 50 条）；为空则跳过
3. **匹配预生成报告**（见下方说明）：
   - 根据问卷 q15（兴趣领域）+ q20（目标行业）匹配 2-3 份专业评估报告（`.md` 文件）
   - 根据 profile（省份、分数、科目）匹配 3-5 所院校评估报告（`.md` 文件）
   - 读取对应文件内容作为上下文
4. 拼接 prompt（profile + 问卷 + 对话摘要 + 专业/院校报告原文），调 Gemini Flash API
5. 把响应 HTML 写入 `/var/www/reports/{userId}-{timestamp}.html`
6. 返回 `{ "url": "http://47.113.125.147/reports/{filename}" }`

**超时：** 120s（含文件读取 + Gemini 生成，上下文较长）

### 预生成报告匹配规则

报告文件已提前跑出，存放于 proxy 服务器：
- 专业报告：`MAJOR_REPORTS_DIR/{专业代码}_{专业名称}.md`（~840 份）
- 院校报告：`UNIV_REPORTS_DIR/{大学名称}.md`

**专业匹配**：把 q15 兴趣领域和 q20 目标行业映射到学科门类代码，扫描目录取前 3 份相关专业文件。优先取用户在对话中提到的专业名称（从对话记录中提取关键词匹配文件名）。

**院校匹配**：调现有 Flask API（`/api/recommend?province=XX&score=XX&category=XX`）获取推荐院校列表，再从 `UNIV_REPORTS_DIR` 读取对应 `.md` 文件（无文件则跳过）。取分数段冲/稳/保各 1-2 所，共 4-5 所。

**Response：**
```json
{ "url": "http://47.113.125.147/reports/user_xxx-1715000000.html" }
```

**proxy `.env` 新增变量：**
- `GEMINI_API_KEY` — Gemini Flash API 密钥
- `REPORTS_DIR` — 生成报告存放目录（默认 `/var/www/reports`）
- `MAJOR_REPORTS_DIR` — 专业评估报告目录（默认 `/opt/gaokao-data/专业评估报告`）
- `UNIV_REPORTS_DIR` — 院校评估报告目录（默认 `/opt/gaokao-data/大学评估报告`）
- `SCORE_API_URL` — Flask 分数推荐 API 地址（默认 `http://159.75.110.157:5000`）

### Nginx 配置（`/reports/` 静态托管，添加到 proxy 服务器 nginx 配置）
```nginx
location /reports/ {
    root /var/www;
    add_header Cache-Control "no-store";
}
```

## Gemini Prompt 结构

```
你是一位专业的高考志愿填报顾问。根据以下考生信息，生成一份完整的个人志愿分析 HTML 报告。

【考生基本信息】
省份：{province} | 科目：{category} | 分数：{score} | 位次：{rank}

【问卷答案（五环框架）】
第一环-学习风格：Q1={q1}, Q2={q2}, Q3={q3}, Q4={q4}, Q5={q5}
第二环-学业现状：优势科目={q6}, 薄弱科目={q7}, 压力来源={q8}, 班级位置={q9}
第三环-家庭背景：父母职业={q10}, 家庭期望={q11}, 城市偏好={q12}, 经济状况={q13}
第四环-能力特质：突出能力={q14}, 兴趣领域={q15}, 排斥方向={q16}
第五环-职业期望：成就感={q17}, 工作价值观={q18}, 工作方式={q19}, 目标行业={q20}, 毕业方向={q21}, 城市偏好={q22}

【AI 对话记录（最近 20 条）】
{conversation_messages}

【专业深度研究资料（已预生成，直接引用）】
{major_report_1_content}

{major_report_2_content}

【院校深度研究资料（已预生成，直接引用）】
{univ_report_1_content}

{univ_report_2_content}

{univ_report_3_content}

输出要求：
- 直接输出完整 HTML，不要代码块标记
- 包含 6 个 Tab：自我评估总结、个人特质分析、专业匹配分析、专业深度研究、大学深度研究、综合决策报告
- Tab 4（专业深度研究）和 Tab 5（大学深度研究）必须基于上方提供的预生成资料，不得自行编造数据
- 使用 ECharts 雷达图展示六维能力
- 深色渐变顶部（#0f1419 → #1a2332），白色卡片内容区
- 其他 Tab 的分析结论需与预生成资料保持一致
```

## 验收标准

- 首页有"生成个人报告"入口，点击进入问卷页
- 问卷 22 题，支持单选/多选，自动保存草稿，返回后回显
- 生成报告时显示 loading，完成后展示复制链接和浏览器打开两个操作
- 报告 HTML 包含 6 个 Tab，雷达图正常渲染
- 同一用户 10 分钟内不重复生成（前端提示"报告已生成"）
- 报告链接可在手机浏览器直接打开
