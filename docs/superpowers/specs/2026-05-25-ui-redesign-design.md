# 小程序 UI/IA 改版设计 · 任务清单首页方案

> 日期：2026-05-25
> 目标：让从未使用过产品的人，打开小程序就清楚知道该做什么；同时让 ¥29 综合报告的转化路径更顺。

---

## 1. 问题诊断

通过审阅 `src/pages/index/index.vue`、`src/pages/assessments/assessments.vue`、`src/pages/profile/profile.vue` 的现状，识别出 6 个根本问题：

1. **首页 4 个并列 CTA**：填基础信息卡、免费咨询入口、3 个测评卡、生成报告入口。新用户进来无法判断「先点哪个」。
2. **测评卡片重复**：首页和「测评」tab 几乎完全相同。
3. **报告入口出现 3 次**：首页底部、测评页底部、我的页都有「生成报告」按钮，反而稀释了入口的权威感。
4. **「第 1 步」无后续地图**：首页标了「第 1 步」，但用户看不到一共有几步、自己处于哪一步。
5. **「我的」tab 几乎只是一张付费卡**：4 个 action button 挤一行，视觉过载；同时缺失「个人资料 / 历史咨询 / 历史报告」这些个人中心标准元素。
6. **「测评」tab 名「测评与报告准备」**：标题暗示报告在这里产出，但实际报告生成入口在别处，造成认知混乱。

## 2. 核心决策

| # | 决策 | 原因 |
|---|------|------|
| 1 | 首页采用「任务清单」结构 | 一屏展示 4 步全貌，新用户秒懂全流程 |
| 2 | tabbar 由 `首页 / 测评 / 我的` 改为 `首页 / 报告 / 我的` | 取消「测评」tab；测评作为首页第 3 步的子任务存在 |
| 3 | 同一时刻只有 1 个橙色 CTA | 当前步骤展开成大卡片附 CTA，其他步骤折叠成小行 |
| 4 | 付费/邀请逻辑从「我的」迁到「报告」tab | 用户「想看报告」时才被引导付费，更自然 |
| 5 | 「我的」回归个人中心标准结构 | 头像 → 考生信息 → 业务列表 → 系统列表 |
| 6 | 顶部「报告完成度」进度卡 | 用 `X/4 步` 的分数感替代百分比，配合颜色变化做付出感→获得感 |

## 3. 信息架构（IA）

```
peng-ge-mini-program
├── 首页 tab           「我的 4 步志愿任务」
│   ├── 进度卡        X/4 步
│   ├── 步骤 1：基础信息（省份/科目/分数）
│   ├── 步骤 2：和峰哥聊聊        → /pages/chat/chat
│   ├── 步骤 3：3 项测评           → 点开展示 五环/MBTI/霍兰德 子任务
│   └── 步骤 4：生成报告           → /pages/report tab
├── 报告 tab           三种状态
│   ├── 未解锁         紫色锁屏 + 邀请条 + 8 模块预览
│   ├── 已就绪未付费   绿色徽章 + 双 unlock 入口（¥29 / 邀请 3 人）
│   └── 已解锁         当前报告卡 + 历史报告列表 + 重新生成
└── 我的 tab
    ├── 用户头部       头像 / ID / VIP 徽章
    ├── 考生信息卡     省份 / 科目 / 分数（可编辑）
    ├── 业务列表       咨询记录 / 测评结果 / 邀请好友
    └── 系统列表       隐私保护 / 反馈客服 / 关于
```

废弃的 tab/页面：
- `pages/assessments/assessments.vue` —— 取消 tab，作为「我的测评结果」入口保留为子页（从「我的」进入）
- 首页内的测评卡片块 —— 整块删除（已并入步骤 3）
- 首页内的报告入口 —— 删除（迁到报告 tab）

## 4. 首页详细设计

### 4.1 三种状态

| 状态 | 触发条件 | 关键视觉 |
|------|---------|----------|
| ① 全新用户 | `profile` 三项任一为空 | 4 步全部展示，仅第 1 步橙色 CTA 高亮，其余锁状态 |
| ② 进行中 | `profile` 完成 + 至少 1 项测评未完成 | 当前步骤自动展开（大卡 + 子任务进度 + CTA 按钮）；其他步骤折叠 |
| ③ 已就绪 | 4 步前 3 步全完成 | 进度变绿；底部出现橙色「立即生成报告」大卡，¥29 与「邀请 3 人免费」并排 |

### 4.2 顶部进度卡

```
┌────────────────────────────┐
│ 我的志愿报告           还差 2 步 │
│ 2 / 4 步                       │
│ ████████░░░░░░░░░░             │
└────────────────────────────┘
```

- 数字格式 `X / 4 步`，比百分比更直观
- 颜色：橙色（进行中）→ 绿色（已就绪）
- 副标题文案：`从第 1 步开始` / `还差 2 步` / `准备就绪`

### 4.3 步骤卡（4 个）

| 状态 | 视觉 | 行为 |
|------|------|------|
| `done` | 绿色 ✓ 图标 + 灰色描述 | 点击跳到对应详情页 |
| `active` 折叠 | 橙色数字图标 + 橙色描述 + ›| 点击展开或跳详情 |
| `active` 展开 | 大卡：图标 + 标题 + 子任务进度 + 主 CTA | CTA 直接行动 |
| `locked` | 灰色 🔒 图标 + 灰色描述 | 点击提示「请先完成上一步」 |

4 个步骤定义：

| # | 名称 | 描述（done 时） | 描述（pending 时） | done 判定 |
|---|------|----------------|-------------------|-----------|
| 1 | 填写基础信息 | `广东 · 物理类 · 600分` | `省份、科目、分数 · 30 秒` | `profile.province && profile.category && profile.score` |
| 2 | 和峰哥聊聊志愿 | `已聊 N 轮 · 点击继续` | `AI 帮你理清楚专业方向` | `chatHistory.length >= 3`（产品定义阈值） |
| 3 | 3 项性格测评 | `INTP · RIA · 五环已记录` | `让报告更准确 · 已完成 X/3` | 三项都完成 |
| 4 | 生成志愿报告 | `已生成 · 点击查看` | `¥29 一次解锁 · 邀请 3 人免费` | `report.generated === true` |

### 4.4 步骤 3 展开形态

当步骤 3 是 `active` 状态时，展开为：

```
┌──────────────────────────┐
│ [3]  完成 3 项测评           │
│      让报告更准确 · 已完成 1/3 │
├──────────────────────────┤
│ [五环 ✓] [MBTI →] [霍兰德 —]│
├──────────────────────────┤
│      继续 MBTI 测评 →        │
└──────────────────────────┘
```

- 三个 chip 显示完成态（✓ / → 进行中 / — 未开始）
- 主 CTA 自动指向「下一项待完成的测评」

### 4.5 顶部 greeting

- 全新用户：`你好，先花 30 秒了解一下吧`
- 已填信息：`广东 · 物理 · 600分 · 已完成 2/4`
- 已就绪：`广东 · 物理 · 600分 · 已就绪`

注：greeting 文案是 placeholder，上线后可 A/B 测试。

## 5. 报告 tab 设计

### 5.1 未解锁状态（测评未完成 OR 未付费）

由四块组成：

1. **锁屏 hero**：紫色渐变背景。徽章「还差 N 项测评」/「✓ 资料已就绪」+ 标题 + 副标题 + `¥29` 大字。
2. **邀请进度条**：3 个圆点 dots 表示邀请进度（避免现状的「0 / 3 人」文字感）。
3. **报告内容预览**：8 大模块网格化展示（院校定位/专业匹配/分数策略/风险提示等），降低决策门槛。
4. **报告样例预览**（仅在「已就绪未付费」时出现）：3 张报告截图缩略，可点击放大查看脱敏样例。

「已就绪未付费」状态额外提供两张并排 unlock 卡：
- 主：`💳 立即支付 ¥29`（橙色高亮）
- 副：`👥 邀请 3 人免费`（带 `已邀请 1/3` 进度）

### 5.2 已解锁状态

- **当前报告卡**：橙色渐变背景，显示「最新报告 · 广东物理类 600分」+ 生成时间 + 模块数；下方两个按钮「在线查看」「分享给家长」。
- **历史报告列表**：每条卡片显示标题（如「广东物理类 · 598分」）+ 副标题（生成时间 / 旧分数版）。
- **重新生成按钮**：底部虚线框「+ 重新生成报告（数据有更新）」。

历史报告由用户在数据变更（改分数/重做测评）后主动触发重生，新版本以独立 ID 入库，老版本保留只读。

## 6. 我的 tab 设计

```
┌─────────────────────────┐
│       [头像]               │
│    志愿同学                  │
│    ID: U_177933              │
│   [VIP · 报告已解锁]          │
├─────────────────────────┤
│ 考生信息                      │
│ [广东] [物理] [600]    编辑 › │
├─────────────────────────┤
│ 💬 我的咨询记录          ›    │
│ 🧠 我的测评结果      3/3 ›    │
│ 👥 邀请好友              ›    │
├─────────────────────────┤
│ 🔒 隐私保护              ›    │
│ 💌 反馈/客服             ›    │
│ ⓘ  关于峰哥             ›    │
└─────────────────────────┘
```

- VIP pill：未付费时灰色 `普通用户`；已付费/邀请够时金色 `VIP · 报告已解锁`
- 「我的测评结果」徽章动态显示 `X/3`
- 「邀请好友」入口在 VIP 已开通时仍保留（可邀请他人，体现产品价值）

## 7. 视觉风格说明

- **底色**：从 `#f9fafb` 浅灰过渡到白
- **主色**：橙色 `#f97316` 系（保持现状）
- **解锁卡**：紫色渐变 `#1e1b4b → #312e81 → #4338ca`，带角落金色光晕（保持现状的高级感）
- **完成色**：绿色 `#10b981`
- **关键差异**：现状的「cyber-glow-bg-indigo/orange」整页背景模糊层 **保留但减弱**，避免和单卡内的紫色解锁卡互相干扰
- **图标**：步骤数字 1/2/3/4 在状态卡里用，整体 emoji 数量从现状的「多 emoji 强情绪化」收敛为「每张卡 ≤ 1 个 emoji」

## 8. 状态转换图

```
全新用户 ──填信息──> 进行中 ──完成3测评──> 已就绪 ──付费/邀请够──> 已解锁(报告 tab)
                       │                       │
                       └──── 期间任意可去咨询 ──┘
```

每个状态变化都需触发首页进度卡和步骤卡的 UI 重渲染。

## 10. 不在本次范围

- 报告内容/排版本身的优化（独立工作）
- 微信小程序分享卡片设计（与本次 IA 解耦）
- 多端响应式（小程序固定窄屏）
- 国际化、夜间模式
- 老用户迁移弹窗（首次进入新版时是否需要 onboarding 引导）—— 可在实施阶段决定

## 11. 验收标准

1. 全新用户在首页能在 3 秒内说出「我要做 4 件事」
2. 任意时刻首页只有 1 个橙色 CTA 按钮（除底部锁定状态报告卡外）
3. 「报告」相关入口在产品中只出现在「报告 tab」+ 首页「步骤 4 卡片」共 2 处
4. 「测评」相关入口在产品中出现在「首页步骤 3 卡片」+ 「我的 → 我的测评结果」共 2 处
5. 「我的」页面首屏视觉权重：用户身份 > 考生信息 > 业务菜单（与现状的「付费卡占绝对主导」相反）
