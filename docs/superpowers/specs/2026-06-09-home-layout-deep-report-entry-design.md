# 首页排版与深度报告快捷入口设计

## 目标

改善首页内容偏小、底部留白过多的问题，同时让用户可以从首页直接进入院校和专业深度报告库。

## 信息层级

首页继续以四步志愿规划流程为主，不改变现有流程状态与交互。四步流程下方新增“深度报告库”区块，作为用户完成或查看主流程之外的独立研究入口。

## 快捷入口

使用双列卡片：

- 蓝色“院校深度报告”：看清学校定位、王牌专业与毕业出路。
- 橙色“专业深度报告”：判断专业前景、适合人群与报考风险。

点击院校卡直接进入院校报告搜索模式，点击专业卡直接进入专业报告搜索模式。

## 视觉调整

- 放大品牌名称、招呼语、进度卡、步骤卡和免责声明字号。
- 增加进度卡、步骤卡与快捷入口卡片的内边距和高度。
- 快捷入口卡片使用浅色背景、明确图形标识和右箭头，保持主流程优先级高于快捷入口。
- 保留现有橙色品牌主色；院校入口使用蓝色，专业入口使用橙色。
- 免责声明放在深度报告区块之后，让有效内容自然占用首页下半部分。

## 边界

- 不新增后端接口和数据状态。
- 不修改四步流程完成逻辑。
- 不修改深度报告搜索页，只复用其现有 `mode=university` 和 `mode=major` 参数。

## 验证

- 首页包含两张快捷入口卡及确认后的文案。
- 两张卡分别导航至正确的深度报告模式。
- 小程序开发构建成功。
- 相关首页和深度报告回归测试通过。
