# 山西工程技术学院深度研究报告编写计划

**Goal:** 撰写一篇 8000 字以上的山西工程技术学院深度研究报告。

**Architecture:** 按照学术实力、录取生源、毕业生出路、区位产业、国际化、校园生态、风险提示、总结评价八大板块进行深度剖析。

**Tech Stack:** Markdown, Data Analysis.

---

### Task 1: 撰写“学术实力”章节 (约 1200 字)
- 详述学校历史（阳泉煤专背景）及其在行业内的地位。
- 分析省级“1331工程”支持。
- 重点解读王牌专业：采矿工程（全国应用型第一）、测绘工程等。
- 介绍省级重点实验室、产业学院（智能煤机等）。

### Task 2: 撰写“录取与生源”章节 (约 1000 字)
- 整理 2023-2025 山西省投档分数线与位次。
- 分析 2025 新高考改革后的录取趋势（物理组与历史组）。
- 对比外省（山东、河南、河北、浙江、广东）录取情况。
- 性价比分析：哪些省份考生报考最划算。

### Task 3: 撰写“毕业生出路”章节 (约 1200 字)
- 分析 2023-2024 就业质量报告。
- 解读 87% 就业率背后的含金量（国企占比、行业分布）。
- 探讨 7% 考研深造率的现状与挑战。
- 薪酬水平调研与同类院校对比。

### Task 4: 撰写“区位与产业”章节 (约 1000 字)
- 剖析阳泉市从“煤城”到“数智新城”的转型背景。
- 详述学校与华阳集团、云时代等企业的产教融合模式。
- 评估区位对实习就业的实际影响（利弊分析）。

### Task 5: 撰写“国际化与校园生态”章节 (约 1000 字)
- 国际交流现状：合作院校、交换生机会。
- 校园生活实录：宿舍条件（4/6人间、电梯）、食堂评价。
- 转专业政策、学术氛围（考研风气）。

### Task 6: 撰写“风险提示”章节 (约 800 字)
- 行业依赖风险（煤炭周期）。
- 地理位置限制（三线城市吸引力）。
- 高端人才流失与学科结构单一化问题。

### Task 7: 撰写“总结评价”章节 (约 1800 字)
- 六维打分量化评价。
- 横向对比：山西工程技术学院 vs 山西工学院（或太原工业学院）。
- 报考人群画像：什么样的人最适合报考。
- 最终结论。
