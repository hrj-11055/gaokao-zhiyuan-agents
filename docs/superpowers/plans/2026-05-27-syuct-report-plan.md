# 沈阳化工大学深度研究报告写作计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 生成一篇 8000 字以上的沈阳化工大学深度研究报告，涵盖学术、录取、就业、区位、国际化、校园生活及风险提示。

**Architecture:** 报告分为八大核心章节，每个章节约 800-1200 字，包含数据图表分析、深层洞察及对比。

**Tech Stack:** Markdown 格式，引用真实搜索数据。

---

### Task 1: 编写学术实力章节 (约 1200 字)

- [ ] **Step 1: 深入分析学科评估结果**。解读 B- 学科（化学工程与技术）在省内及行业内的地位。
- [ ] **Step 2: 详细介绍 4 个国家级特色专业**。分析其课程设置、科研平台及行业影响力。
- [ ] **Step 3: 剖析“菁英班”与“科教融合”**。详细描述与中国科大、中科院的合作模式及其对保研/考研的价值。
- [ ] **Step 4: 评估顶尖资源**。列举国家级、省级实验室及领军人才（院士、长江学者等）。

### Task 2: 编写录取与生源章节 (约 1000 字)

- [ ] **Step 1: 整理 2023-2025 辽宁省内数据**。分析物理类、历史类分数趋势及热门专业溢价。
- [ ] **Step 2: 抽取典型外省数据 (河北、河南、四川、江苏)**。分析该校在不同地区的竞争烈度与性价比。
- [ ] **Step 3: 分析中外合作办学分数差**。探讨低分进入王牌专业的策略可行性。

### Task 3: 编写毕业生出路章节 (约 1200 字)

- [ ] **Step 1: 深度解读 33% 的深造率**。详细拆解 16% 考研率与 16% 第二学士学位的逻辑。
- [ ] **Step 2: 分析就业去向 (行业与企业)**。重点解读 15% 央企入职率及重点签约单位 (中石油、恒力等)。
- [ ] **Step 3: 薪酬与满意度评估**。结合地域 (留辽率 60%) 分析 5000 元月薪的实际生活质量。

### Task 4: 编写区位、产业与国际化章节 (约 1000 字)

- [ ] **Step 1: 城市产业耦合度分析**。沈阳经济技术开发区的产业背景如何支撑实习就业。
- [ ] **Step 2: 国际化合作详解**。详细介绍与俄罗斯伊尔库茨克的 4+0 能源与动力工程项目。

### Task 5: 编写校园生态与风险提示章节 (约 1000 字)

- [ ] **Step 1: 校园生活实录**。描述宿舍 (无空调)、食堂 (价格便宜) 及转专业 (前 20%) 的真实体验。
- [ ] **Step 2: 风险与争议分析**。分析学科单一性、设施老旧度及行业波动风险。

### Task 6: 编写对比与总结评分 (约 1400 字)

- [ ] **Step 1: 横向对比：沈阳化工大学 vs 辽宁石油化工大学**。从历史沿革、学科强度、就业区域做全方位对比。
- [ ] **Step 2: 六维量化打分**。给出学术、出路、区位、国际化、生态、声誉的分值及依据。
- [ ] **Step 3: 报考决策模型**。为不同分段、不同意向的学生提供具体报考建议。

### Task 7: 整合、润色与字数达标检查

- [ ] **Step 1: 检查全文逻辑衔接**。
- [ ] **Step 2: 增加深度洞察与专家点评语气**。
- [ ] **Step 3: 确保字数超过 8000 字**。
