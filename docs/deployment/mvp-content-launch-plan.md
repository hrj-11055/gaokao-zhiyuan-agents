# MVP 内容排期与上线验收表

> 创建日期：2026-05-26
> 目标：把已打通的支付会员链路整理成可对外发布的最小可行产品，并在正式上线前完成内容、功能和异常场景验收。

## 当前 MVP 范围

- 小程序 API Base：`https://gaokao.aicoming.cn`
- 核心转化：用户完成资料和测评后，支付 19.9 元解锁会员权益。
- 会员权益：综合志愿报告、报告 PDF 下载、学校/专业深度 PDF 下载、家长分享。
- 替代解锁：邀请 5 位有效新用户，或使用后台发放的邀请码。
- 已完成基础能力：小程序备案、微信支付 1 元真机测试、数据导入、PDF 下载、HTTPS 合法域名。

## 两天打磨排期

### Day 1：支付与权益收口

- [ ] 恢复正式价格：后端 `MEMBERSHIP_PRICE_CENTS=1990`，小程序展示 `¥19.9`。
- [ ] 使用新测试账号完成 19.9 元真机支付。
- [ ] 验证支付后会员状态为 `active/payment`。
- [ ] 验证综合报告生成、报告 HTML、综合 PDF、深度 PDF 下载。
- [ ] 验证深度 PDF 下载剩余次数扣减。
- [ ] 验证取消支付、重复点击支付、已开通会员再次点击支付。
- [ ] 验证支付回调重复通知、金额不一致、订单不存在等后端异常路径。

### Day 2：内容、邀请码与发布前验收

- [ ] 完成邀请码生成、查询、停用、兑换测试。
- [ ] 验证邀请 5 人解锁链路。
- [ ] 检查会员权益文案：价格、有效期、权益范围、PDF 次数限制。
- [ ] 检查支付页文案：不得出现测试价、限免调试、备案中等旧文案。
- [ ] 检查报告页空状态、未解锁状态、已解锁状态、生成失败提示。
- [ ] 检查客服/售后话术：支付成功未解锁、重复扣款、邀请码无效、PDF 次数耗尽。
- [ ] 上传体验版后按真机验收表完整跑一遍。

## 最终上线验收表

- [ ] 小程序体验版使用 `https://gaokao.aicoming.cn`。
- [ ] 小程序内无测试价、测试入口、调试限免入口。
- [ ] 19.9 元支付成功后，订单为 `paid`，会员为 `active/payment`。
- [ ] 支付取消不解锁会员，提示清楚。
- [ ] 支付成功但回调延迟时，刷新/轮询可恢复状态。
- [ ] 有效邀请码可解锁会员，无效/过期/用尽邀请码不可解锁。
- [ ] 邀请 5 人链路可解锁会员。
- [ ] 综合报告生成成功，HTML 可打开，PDF 可下载。
- [ ] 深度 PDF 下载成功，剩余次数正确扣减。
- [ ] 深度 PDF 次数耗尽后提示清楚。
- [ ] 微信登录、资料保存、三项测评、报告生成完整链路无阻塞。
- [ ] 小程序备案、服务器域名、request/downloadFile 合法域名均已确认。
- [ ] 线上日志可定位登录、下单、回调、解锁、报告生成问题。

## 不做范围

- 不接入新的服务器链路。
- 不引入新的后端入口方案。
- 不扩展新的大功能，优先保证支付会员 MVP 稳定可验收。
