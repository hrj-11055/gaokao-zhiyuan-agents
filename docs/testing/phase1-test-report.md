### 主要问题

1. **回答偏长（E类）**：Q5-Q9 五题超过800字，Q8达1079字。目标应控制在400-600字
2. **知识库引用不明显（F类）**：多数回答像是LLM自身知识，而非引用KB数据。Q14是唯一明确引用分数线的
3. **Q12 未引用语料（F类）**：问了"张雪峰怎么看"但回答没有引用KB-1中的张雪峰原话

### 下一步优化方向

1. **长度控制**：在 Prompt 中加字数约束（"标准回答控制在400-600字"），或调低 max_tokens
2. **强化数据引用**：在 Prompt 中加"引用知识库数据时必须标注'根据数据...'"
3. **Q12 语料引用**：可能需要优化 KB-1 的检索匹配，或 Prompt 中加"提到张雪峰时必须引用其原话"

## Prompt 调优 v2（2026-04-21）

### 调优内容

针对上述 3 个主要问题，在 Prompt 末尾追加了 3 段调优指令：

1. **长度控制（严格执行）**：按场景设字数上限（追问50-150字、标准回答300-500字、复杂场景上限700字），禁止开头废话和总结段落
2. **数据引用（强制）**：涉及具体学校时必须先查参考资料，引用格式"根据2024年数据，XXX大学在XX最低录取分是XXX分"，禁止凭记忆给分数
3. **张雪峰观点引用**：用户问"张雪峰怎么看"时先引用语料原话，格式"关于这个问题，张老师的观点是……"

同时将 `max_tokens` 从 1024 降至 800。
