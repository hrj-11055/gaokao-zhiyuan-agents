## 六、问题分析

### 问题 1：Q20 完全未回答（C类 → 严重）

**v1 回答**（428字）：分析了学医投入产出比、适合/不适合人群、推荐口腔/麻醉替代
**v3 回答**（148字）：只问了三个问题就结束了，完全没有回答"学医怎么样"

**原因分析**：max_tokens=500 导致模型优先追问，回答空间不够。或者是 Prompt 中追问指令太强，模型认为应该先问完再答。

**修复方案**：将 max_tokens 提回到 640，或者在 Prompt 中加一条"用户同时问了具体问题时，先给简短回答再追问"。

### 问题 2：Q5/Q6 仍然过长（E类）

Q5 (888字) 和 Q6 (842字) 依然超出 700 字目标。max_tokens=500 对 DeepSeek 的中文输出限制约 800-1000 字，无法有效截断到 700 字以下。

**修复方案**：在 Prompt 中进一步强调长度约束，或者接受核心场景题（Q5-Q8）允许 700-800 字。

### 问题 3：Q11 反而变长（E类）

v1 是 367 字（偏短），v3 反而变成 739 字。可能是因为 v2 Prompt 加了更多引用指令，导致模型主动展开。

## 七、结论与建议

### 调优效果总结

| 调优动作 | 效果 |
|---------|------|
| Prompt v2（长度+引用+语料） | ✅ KB引用从1/20提升到8/20 |
| max_tokens 1024→800 | ✅ 平均长度降13% |
| max_tokens 800→500 | ⚠️ 长度再降9%，但Q20被截断导致未回答 |

### 建议下一步

1. **max_tokens 调回 640**：500 太小导致 Q20 无法完整回答，640 是更合理的折中（约 900-1000 中文字上限）
2. **接受核心场景 700-800 字**：Q5-Q8 这种涉及具体学校推荐的场景，700-800 字是合理的
3. **Prompt 中补充**："用户同时问了具体问题时，先给简短回答（2-3个要点），再追问缺失信息"——解决 Q20 的问题
4. **暂不继续调优**：当前整体通过率 75%（15/20），知识库引用显著提升，继续微调收益递减
