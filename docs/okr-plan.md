### KR4：综合报告生成 Workflow + 报告页（截止 05/09）

这是 MVP 最核心的新功能。

**4.1 Dify 报告 Workflow 设计（截止 05/07）**

新建一个 Dify Workflow 应用（非 Chatflow），专门用于报告生成。

```
报告生成 Workflow（Dify）
│
├── 节点1: 开始 — 接收 inputs（province, score, rank, category, subjects, user_id）
│
├── 节点2: HTTP 工具 — 调用 gaokao-api 查分
│   GET gaokao-api:5001/api/recommend?province=X&score=X&category=X&year=2024
│   → 返回冲/稳/保院校列表
│
├── 节点3: 知识库检索 — RAG 查询相关专业
│   检索 KB-3（专业百科）：基于兴趣和分数段匹配适合的专业(Top5)
│
├── 节点4: 知识库检索 — RAG 查询目标院校
│   检索 KB-4（院校研究）：基于推荐院校列表检索详细报告 （Top5）
│
├── 节点5: LLM 生成报告（DeepSeek V4）
│   Prompt 模板（见下方报告 Prompt 要点）
│   输入：用户画像 + 查分结果(省份、位次) + 专业检索 + 院校检索
│   输出：结构化 Markdown 报告
│
└── 节点6: 结束 — 返回报告 Markdown
  Markdown 转 HTML 文件
```

**报告 Prompt 要点**：
- 人设：张雪峰风格，直白务实
- 输入约束：只用 HTTP 工具和 RAG 返回的真实数据，禁止编造
- 输出结构：个人画像 → 专业推荐（3-5 个）→ 院校推荐（冲/稳/保）→ 避坑建议 → 行动清单
- 每个推荐必须附理由和具体数据支撑
