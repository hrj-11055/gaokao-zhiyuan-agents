# Phase 2.2 — KB-2 录取分数线数据接入

> 排期：Week 1（04/16 - 04/18）
> 前置依赖：爬虫完成（crawl_scores_v4.py 运行结束）
> 阻塞任务：Phase 3.1 知识库补全

---

## 1. 如何完成

### 步骤

1. **确认爬虫完成**
   ```bash
   # 检查爬虫进程
   ps aux | grep crawl_scores_v4 | grep -v grep
   # 检查日志结尾
   tail -5 /tmp/crawl_v4_local.log
   # 检查输出文件
   ls -lh /tmp/gaokao_scores/
   ```

2. **上传到 Dify 知识库**
   ```bash
   python3 upload_kb2_to_dify.py
   ```
   脚本会自动创建 KB-2 数据集并上传两个文件：
   - `kb2-scores-河北.md`
   - `kb2-scores-广东.md`

3. **接入 Chatflow 知识检索节点**
   - 登录 Dify → 张雪峰高考志愿填报助手 → 编排页面
   - 点击「知识检索」节点 → 添加数据集 → 选择 KB-2
   - 重新发布

4. **验证数据可检索**
   - 在预览面板输入："武汉大学在河北2024年录取分数线"
   - 确认回答中引用了具体的分数线数据

### 可能遇到的问题

| 问题 | 解决方案 |
|------|---------|
| 上传文件太大（>15MB） | Dify 单文件限制 15MB，需要拆分为多个文件（按年份或按字母分段） |
| Economy 模式检索不准 | 等配置 ZhiPu embedding 后切换为 high_quality 模式 |
| 数据格式不对 | 确认 Markdown 表格格式完整，每行以 `|` 结尾 |
