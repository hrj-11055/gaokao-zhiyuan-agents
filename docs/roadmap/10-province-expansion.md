### 技术执行

#### 数据爬取

复用 `crawl_scores_v4.py`，只需修改省份配置：

```python
# 修改 PROVINCES 字典即可
PROVINCES = {
    "13": "河北", "44": "广东",  # 已有
    "41": "河南", "37": "山东",  # 新增
    "51": "四川", "43": "湖南",
    "42": "湖北", "32": "江苏",
}
```

每个省份约需 2-3 小时爬取（500 学校 × 3 年 × 5 秒间隔）。

#### 知识库扩展

- 每个省份的分数线数据单独一个文件
- 上传到同一个 KB-2 数据集（或按省份分数据集）
- 补充对应省份的批次线、一分一段表

#### Prompt 调整

- 去掉 prompt 中关于"河北/广东"的特殊处理
- 增加"根据用户所在省份自动匹配对应数据"的指令

### 实施步骤

1. 修改爬虫配置，启动第一批 6 省的数据爬取
2. 爬取完成后上传到 Dify
3. 补充各省批次线数据
4. 更新 prompt 适配多省份
5. 每省测试 3-5 个典型问题
