> 排期：Week 2（04/23 - 04/27）
> 前置依赖：Phase 2.1 测试报告、Phase 2.2 KB-2 接入
> 阻塞任务：Phase 3.2 多轮对话优化

## 1. 如何完成

### 需要补充的数据

#### KB-4：学校基本信息
- 985/211 标识
- 公办/民办属性
- 学校所在省份和城市
- 王牌专业/优势学科
- 双一流学科

**数据来源：**
- 掌上高考 school info API：`https://static-data.gaokao.cn/www/2.0/school/{id}/info.json`
- 教育部公示名单
- 编写爬虫批量抓取（复用 crawl_scores_v4.py 的框架）

#### KB-5：各省批次线
- 2023-2025 年各省本科一批/二批/专科批分数线
- 物理类/历史类分别列出

**数据来源：**
- 掌上高考批次线 API
- 各省教育考试院官网（手动整理）
- 格式化为 Markdown 表格

#### KB-6：一分一段表（位次对照）
- 2023-2025 年河北、广东的一分一段表
- 用于"考了 X 分，大概排名多少"的查询

**数据来源：**
- 各省教育考试院公布的数据
- 可先做河北、广东两省

### 执行步骤

1. 编写学校信息爬虫（从已有 school_id 列表批量抓取）
2. 手动整理各省批次线数据（数据量不大，可手动 + 半自动）
3. 一分一段表爬取或手动整理
4. 格式化为 Markdown 文件
5. 上传到 Dify 创建 KB-4、KB-5、KB-6 数据集
6. 接入 Chatflow 知识检索节点
7. 测试验证
