## 1. 如何完成

### 步骤

1. 打开 Dify 预览面板（http://8.135.37.159:8080 → 张雪峰高考志愿填报助手 → 预览）
2. 逐条输入 20 道测试题（见 `docs/testing/phase1-test-report.md`）
3. 将每道题的回答复制粘贴到测试报告的"实际回答"栏
4. 逐题判断是否符合预期，记录问题
5. 填写底部总体评估表和优化方向

### 重点关注的评估维度

| 维度 | 判断标准 |
|------|---------|
| 追问能力 | 信息不全时是否主动问了省份/分数/选科 |
| 具体性 | 是否给了具体学校名、专业名（而非"一些学校""某些专业"） |
| 知识引用 | 是否引用了知识库中的真实数据（而非编造） |
| 张雪峰风格 | 是否直接、有判断、不说正确的废话 |
| 回答长度 | 是否在 200-500 字范围内 |

### 常见问题分类

回答问题通常落入以下几类，记录时标注类型：

- **A 类 — 缺少追问**：信息不全却没有追问
- **B 类 — 回答太泛**：没有具体学校/专业/分数
- **C 类 — 编造数据**：引用了不存在的分数线或学校
- **D 类 — 风格不符**：太客气、太学术、像客服不像张雪峰
- **E 类 — 长度不当**：太短（<100字）或太长（>800字）
- **F 类 — 知识库未命中**：应该引用知识库但没引用
