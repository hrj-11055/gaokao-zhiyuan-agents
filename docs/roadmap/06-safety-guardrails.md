# Phase 3.3 — 安全护栏与免责声明

> 排期：Week 3（04/30 - 05/04）
> 前置依赖：Phase 2.3 Prompt 调优
> 阻塞任务：Phase 4.2 微信小程序接入

---

## 1. 如何完成

### 需要覆盖的安全场景

#### 1.1 免责声明（必须）

在 System Prompt 末尾追加：

```
## 免责声明（每次回答涉及具体分数线或录取概率时必须附加）
"以上建议仅供参考，实际录取分数线请以各省教育考试院官方公布为准。
志愿填报是重要决策，建议结合官方数据和学校招生简章综合判断。"
```

#### 1.2 敏感话题拦截

在 Prompt 中增加禁止规则：

```
## 敏感话题处理
以下话题不回答，礼貌拒绝并引导回志愿填报：
- 政治类话题
- 宗教话题
- 涉及具体政策评价
- 与高考志愿填报无关的任何话题

拒绝话术："这个不是我的专业范围，我是专门帮你填志愿的。咱们还是聊聊你的志愿吧，你是哪个省的考生？"
```

#### 1.3 数据不确定性声明

当引用知识库数据时，必须标注年份来源：

```
## 数据引用规范
- 引用分数线时必须标注年份："根据2024年的数据..."
- 如果知识库中没有该学校/专业的数据，明确说"我手头暂时没有这所学校的详细数据"
- 禁止编造或推测具体分数
```

#### 1.4 极端情况处理

| 用户输入 | 处理方式 |
|---------|---------|
| 问非志愿填报问题 | 礼貌拒绝 + 引导回正题 |
| 输入明显不合理分数（如 900 分） | 提醒检查分数是否正确 |
| 情绪化表达（焦虑、沮丧） | 给予鼓励 + 务实建议 |
| 要求保证录取 | 明确告知不存在保证录取，给出风险提示 |

#### 1.5 Dify 内容审核（可选）

Dify 自带内容审核功能，可以在 LLM 节点前后各加一个审核节点：
- 输入审核：过滤敏感词
- 输出审核：确保回答不含不当内容

### 实施步骤

1. 更新 System Prompt，加入上述所有安全相关指令
2. 测试敏感话题拦截效果
3. 测试免责声明是否自动附加
4. 可选：配置 Dify 内容审核节点
