## 二、分数线查询 API 开发

### 3. Flask API 服务（gaokao-api/app.py）
开发 7 个 API 端点，供 Dify HTTP 工具节点和综合报告生成调用：

| 端点 | 功能 | 用途 |
|------|------|------|
| `GET /api/health` | 健康检查 | 服务监控 |
| `GET /api/stats` | 数据统计 | 运营看板 |
| `GET /api/scores/match` | 冲稳保三档匹配 | 志愿推荐核心 |
| `GET /api/scores/schools/<name>/provinces/<prov>` | 学校专业分数线 | 院校详情 |
| `GET /api/scores/majors/<keyword>` | 专业关键词查询 | 专业搜索 |
| `GET /api/scores/recommend` | 综合推荐 | 报告生成 |

- 支持 **本地 JSON 模式**（`USE_JSON=true`，无需数据库即可本地开发测试）
- 支持 **PostgreSQL 模式**（生产部署，查询更快更稳定）

### 4. 代码审查与问题修复

对 API 代码进行了全面审查，发现并修复 7 个问题：

| 问题 | 严重度 | 影响 | 修复方案 |
|------|--------|------|----------|
| 科类名称不匹配 | P0 | 查"物理类"找不到 199K 条"理科"数据 | 添加归一化映射：理科→物理类、文科→历史类 |
| DB 连接泄漏 | P0 | 异常时连接不归还池，生产环境耗尽连接 | 所有端点改用 try/finally |
| 每次请求全表扫描 90 万条 | P1 | 响应慢（99ms→7ms） | 构建 (省份, 年份, 科类) 索引 |
| limit 参数无上限 | P1 | 可传 999999 导致内存溢出 | 限制最大 50/100 |
| Flask debug=True 硬编码 | P1 | 生产环境安全风险 | 改为读取环境变量 |
| 体育/艺术数据干扰匹配 | P2 | 冲稳保推荐包含无关数据 | 索引构建时过滤 |
| province_id_map 重复定义 | P2 | 维护成本 | 提取为模块常量 |
