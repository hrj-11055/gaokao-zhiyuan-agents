# 30 题标准测试集

> 用途：W5 质量验收。先用 30 题建立质量闭环，替代原 100 题批量测试。
> 评分维度：准确性 40%、实用性 30%、风格一致性 20%、追问能力 10%。编造不存在的院校、专业、分数线直接判不合格。

| ID | 类别 | 测试问题 | 核心检查点 |
|---|---|---|---|
| Q01 | 志愿填报策略 | 我是广东物理类 600 分，想冲 211，应该怎么分配冲稳保？ | 给出冲稳保比例、风险提醒、需要位次 |
| Q02 | 志愿填报策略 | 河北物理类 530 分，家庭条件一般，优先保专业还是保学校？ | 明确就业导向和保底策略 |
| Q03 | 志愿填报策略 | 广东历史类 560 分，想学法学，怎么填比较稳？ | 院校层次、专业热度、法学风险 |
| Q04 | 志愿填报策略 | 刚过本科线 20 分，是选民办本科还是好一点的专科？ | 成本、学历、就业路径对比 |
| Q05 | 志愿填报策略 | 中外合作办学一年学费很贵，值不值得为了学校层次去读？ | 预算、保研/升学、专业质量 |
| Q06 | 志愿填报策略 | 我想去大城市，但分数只能去偏远地区好学校，怎么取舍？ | 城市和学校平台取舍逻辑 |
| Q07 | 院校推荐/分数线 | 广东物理类 580 分，2024 年能考虑哪些大学？ | 不编造，提示需按位次核验 |
| Q08 | 院校推荐/分数线 | 河北物理类 620 分，能冲哪些 211？ | 给出分层建议和数据核验 |
| Q09 | 院校推荐/分数线 | 广东历史类 520 分，有哪些省内学校比较稳？ | 省内院校分层，提醒批次线 |
| Q10 | 院校推荐/分数线 | 2024 年广东本科线是多少？物理类和历史类分别说。 | 分数线准确，不确定则说明来源限制 |
| Q11 | 院校推荐/分数线 | 深圳大学和广东工业大学，广东物理类 560 分选哪个？ | 专业优先，不简单排名 |
| Q12 | 院校推荐/分数线 | 燕山大学和河北工业大学，河北物理类 570 分怎么选？ | 211 属性、专业、地域权衡 |
| Q13 | 专业分析 | 人工智能和计算机科学与技术有什么区别？哪个更推荐？ | 课程、就业、报考分数差异 |
| Q14 | 专业分析 | 电气工程及其自动化适合普通家庭孩子吗？ | 就业确定性、电网、行业路径 |
| Q15 | 专业分析 | 土木工程现在还能不能报？ | 行业周期和适合人群 |
| Q16 | 专业分析 | 新闻传播专业是不是坑？哪些人适合学？ | 风险直说，不一刀切 |
| Q17 | 专业分析 | 临床医学分数高、周期长，还值得冲吗？ | 学制、读研、家庭承受能力 |
| Q18 | 专业分析 | 法学和金融，家里人让我选金融，我想选法学，怎么办？ | 职业门槛、家庭资源、追问 |
| Q19 | 测评/报告联动 | 我 MBTI 是 INTJ，霍兰德偏 I/C，适合什么专业方向？ | 能结合测评，不绝对化 |
| Q20 | 测评/报告联动 | 如果五环问卷显示我抗压一般，还适合学医吗？ | 结合性格和专业压力 |
| Q21 | 测评/报告联动 | 测评结果和我想学的专业冲突，以哪个为准？ | 测评辅助定位，不替代选择 |
| Q22 | 测评/报告联动 | 生成综合报告前，我还需要补充哪些信息？ | 省份、科类、分数、位次、偏好 |
| Q23 | 边界与异常 | 我考了 0 分，能上清华吗？ | 拒绝胡说，温和处理 |
| Q24 | 边界与异常 | 我不想告诉你省份和分数，你直接推荐学校。 | 主动追问，不乱推荐 |
| Q25 | 边界与异常 | 给我保证某个学校一定录取，可以吗？ | 明确不能保证，解释风险 |
| Q26 | 边界与异常 | 你是不是张雪峰本人？ | 身份说明，不冒充 |
| Q27 | 张雪峰风格一致性 | 女生学计算机好吗？家里担心太累。 | 直白务实，有条件建议 |
| Q28 | 张雪峰风格一致性 | 男生学护理是不是没面子？ | 现实就业导向，反偏见 |
| Q29 | 张雪峰风格一致性 | 普通家庭孩子最应该避开什么专业？ | 观点明确但不过度绝对 |
| Q30 | 张雪峰风格一致性 | 分数不高但想赚钱，专业应该怎么选？ | 现实路径、技能和地域建议 |
