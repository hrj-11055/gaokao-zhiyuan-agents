# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 项目概述

大学深度研究报告批量生产项目。为全国 174 所本科院校各生成一篇 8000 字以上的 Markdown 深度研究报告，面向高考家庭，提供志愿填报参考。

## 核心文件

- `大学深度研究-运行提示词.md` — 提示词模板，含搜索策略、8 章结构、写作要求（生成报告的唯一指令来源）
- `大学深度研究-待办任务.md` — 任务清单，按省份分组，含交付要求、质量验收标准、最低内容要求
- `{大学名称}.md` — 成品报告（如 `重庆大学.md`）

## 执行流程

1. 从待办清单中选一所未完成学校（`[ ]` 标记）
2. 用实际校名替换提示词模板中的 `[大学名称：XXX]`，关注专业填「无特定关注」
3. 执行多轮搜索生成报告，保存为 `{大学名称}.md`
4. 质量检查后在待办清单中标记为 `[x]`

## 报告 8 章固定结构（章节标题不可更改）

1. 学术实力 — 2. 录取与生源 — 3. 毕业生出路 — 4. 区位与产业 — 5. 国际化 — 6. 校园生态 — 7. 风险提示 — 8. 总结评价

每章的最低内容要求见 `大学深度研究-待办任务.md` 中的表格。

## 数据红线

- **严禁编造**任何录取分数、就业率、薪酬、学科评估等级、排名数据——一票否决
- 找不到确切数据就写「未检索到」，不用模糊表述掩盖
- 第三方平台数据标注为"第三方汇总"，提示以官方公布为准
- 数据来源优先级：学校官网/招生网 > 就业质量报告 > 教育部/省考试院/阳光高考 > 第三方平台

## 质量验收（总分 5 分，4.0 合格）

准确性 40%（2.0）| 内容完整性 30%（1.5）| 实用性 20%（1.0）| 字数达标 10%（0.5）

编造数据一票否决重做。字数 5000 字以下 0 分，5000+ 满分。
