## 模块五：职业路径图

### 路径一：数据分析/商业智能精英

`本科名校 + 核心技能（Python/SQL/Tableau）` → `名企数据分析实习` → `进入互联网/金融行业 BI 团队` → **成长为数据驱动型管理人才**

### 路径二：考研深造→数据科学家

`本科阶段打好数理基础` → `考研至统计学/计算机/商业分析硕士` → `进入头部企业数据科学团队` → **成为不可替代的数据科学家**

`考取公务员/事业单位` → `进入政府部门数据管理中心或国企数字化部门` → `参与数据治理与数字化转型项目` → **稳定中速成长**

## 模块六："反差与揭秘"趣味卡片

### 6.1 刻板印象 vs 现实

**你以为的 大数据管理与应用 学生**：每天对着酷炫的数据可视化大屏，运筹帷幄，用 AI 模型预测市场走势，年薪百万的"数据精英"。

**真实的 大数据管理与应用 学生**：大一大二在跟高数、线代、概率论死磕，大三发现 Python 和 SQL 还没学扎实，大四投简历时发现——算法岗打不过计科学生，管理岗打不过商学院学生，数据分析岗打不过统计学学生。最后在某个传统企业的信息化部门，每天用 Excel 做周报，偶尔写几句 SQL。"懂数据的管理者"听起来很美，但本科四年很难把"数据"和"管理"都学精。

### 6.2 "一句话入坑测试"

**场景**：你是一家连锁奶茶店的店长，发现上个月利润下滑了 15%，你需要找到原因。

- **A.** 先去问各店员最近客流怎么样、有没有什么特殊情况 → 你更偏"管理者思维"，善于沟通和直觉判断，但可能忽略数据背后的深层规律。
- **B.** 调出 POS 系统数据，按品类/时段/门店维度交叉分析，找出利润下滑的精确原因 → 你具备"数据驱动"思维，善于用量化方法拆解问题，这正是本专业的核心训练。

**匹配指数**：选 B → ★★★★★（5 星，高度匹配）    选 A → ★★☆☆☆（2 星，可能更适合传统管理类专业）

### 7.2 一句话情景测试

**问题**：朋友推荐你一款"AI 智能选股"App，号称年化收益 30%，你会怎么做？

- **A.** 先下载试试，反正免费，万一真赚钱呢 → 你倾向于"先行动再验证"，风险偏好较高，适合创业者或执行型岗位。

**匹配指数**：选 B → ★★★★★（5 星，高度匹配）    选 A → ★★☆☆☆（2 星，建议避开数据分析方向）
