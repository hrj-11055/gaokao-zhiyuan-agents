## 模块四：专业横向对比

### 对标专业：蒙医学（100504K）

选择理由：蒙医学与藏医学同属民族医学类（1005），均为中国特色少数民族医药学科，在政策环境、就业模式、学科特征上高度可比。

| 对比维度 | 藏医学（100503K） | 蒙医学（100504K） |
|----------|-------------------|-------------------|
| 学科门类 | 医学→中医学类 | 医学→中医学类 |
| 修业年限 | 5年 | 5年 |
| 开设院校数 | ~6-8所 [待核实] | ~4-6所 [待核实] |
| 就业地域 | 西藏、青海、川西、甘南 | 内蒙古、辽宁、新疆 |
| 产业规模 | ~80亿元 [待核实] | ~50亿元 [待核实] |
| 政策保护级别 | 高 | 高 |
| 薪资水平 | 3500-5000元/月起 [待核实] | 3500-5000元/月起 [待核实] |
| 国际影响 | 南亚地区 | 蒙古国、俄罗斯布里亚特 |
| 考研深造点 | 极少 | 极少 |
| 综合推荐度 | 🟡 谨慎报考 | 🟡 谨慎报考 |

### 对比结论

藏医学与蒙医学是"难兄难弟"——同为民族医学，共享政策红利，也共享地域局限。藏医学在产业体量和国际影响上略优于蒙医学（藏药产业化程度更高、南亚辐射范围更广），但两者的本质困境相同：**专业壁垒极高、就业地域极窄、职业天花板明显**。

**如果在两者间纠结**：看地域。家在藏区或对藏文化更感兴趣→藏医学；家在内蒙或有蒙族背景→蒙医学。其余情况，两者无本质差异。

## 模块五：职业路径图

### 路径A：公立藏医院临床医师（概率 ~55%）

```
藏医学本科（5年）
    ↓
藏医执业医师考试（通过率 ~45% [待核实]）
    ↓
住院医师规范化培训（3年）
    ↓
藏医院住院医师（月薪 4000-6000元 [待核实]）
    ↓ 3-5年
主治医师（月薪 7000-10000元 [待核实]）
    ↓ 5-8年
副主任医师（月薪 10000-15000元 [待核实]）
    ↓
主任医师（月薪 12000-18000元 [待核实]）
```

**优势**：稳定、有编制、社会地位高（在藏区）
**劣势**：晋升慢、收入上限低（相比西医）、地域锁定
**适合**：追求稳定、愿意扎根藏区的考生

### 路径B：藏药企业研发/生产（概率 ~20%）

```
藏医学本科
    ↓
考研（药理学/中药学方向）
    ↓
藏药企业研发岗（月薪 5000-8000元 [待核实]）
    ↓ 3-5年
研发主管/项目经理（月薪 8000-15000元 [待核实]）
    ↓
研发总监/自主创业
```

**优势**：收入天花板更高、可迁移至中药企业
**劣势**：需要额外考研转型、藏药企业规模小
**适合**：对药物研发感兴趣、愿意接受更大不确定性的考生

### 路径C：藏医学教育/研究（概率 ~15%）

```
藏医学本科
    ↓
考研→博士
    ↓
高校教职/研究院所（月薪 6000-12000元 [待核实]）
    ↓
副教授/教授
```

**优势**：学术自由、可参与藏医药文化传承项目
**劣势**：岗位极少、竞争激烈、博士几乎为必选项
**适合**：热爱学术研究、有志于藏医药文化保护传承的考生

### 路径D：其他（转行/自由执业）（概率 ~10%）

包括：开设私人藏医诊所、转型健康管理、考取中西医结合方向、考公务员等。

## 模块七：专业气质人格标签

### 🏷️ 藏医学人格画像

**核心标签**：

| 标签 | 含义 |
|------|------|
| 🏔️ 文化守望者 | 对民族文化遗产有使命感，愿意为传承贡献力量 |
| 🧘 耐心型人格 | 能接受长周期学习（5年本科+3年规培）和缓慢晋升 |
| 🌍 扎根型 | 不追求大城市，愿意在藏区长期生活和工作 |
| 📖 传承者 | 尊重传统知识体系，有师徒传承意识 |
| 💪 抗压型 | 能适应高原环境和相对艰苦的生活条件 |

### MBTI 倾向

**推荐人格类型**：ISFJ（守卫者）、INFJ（提倡者）

**原因**：藏医学需要极强的耐心、对传统文化的敬畏感、对患者的细致关怀。ISFJ 的守卫者特质与藏医学"守护传承"的学科精神高度契合。INFJ 的使命感则适合有志于藏医药文化保护与传播的考生。

### ⚠️ 不适合人群

- 追求高薪快速回报的考生（起薪低、晋升慢）
- 不愿意离开大城市的考生（就业地域极窄）
- 对藏文化没有兴趣的考生（学习动力会严重不足）
- 身体无法适应高原环境的考生（多数实习和工作在高海拔地区）
