## 模块一：专业概况与全景认知

### 1.1 专业定义

曲艺是中国独有的以"口语说唱"为基本表演手段的艺术形式，涵盖相声、评书、快板、大鼓、琴书、弹词、鼓曲、单弦、岔曲等多种表演门类。曲艺专业（130314TK）培养具备曲艺表演、创作、教学及非遗保护推广能力的复合型人才。

### 1.2 专业基本信息

| 项目 | 内容 |
|------|------|
| 专业代码 | 130314TK |
| 学科门类 | 艺术学（13） |
| 专业类 | 戏剧与影视学类（1303） |
| 专业类型 | 特设专业（T）+ 国家控制布点（K） |
| 学制 | 4年（本科） |
| 授予学位 | 艺术学学士 |
| 开设院校 | 全国仅3所本科院校开设（截至2025年） |

### 1.3 学什么

核心课程体系涵盖：相声表演与创作、评书表演、快板艺术、鼓曲演唱、曲艺概论、中国曲艺史、曲艺作品赏析、台词与朗诵、声乐基础、形体训练、戏曲表演基础、文艺美学、非物质文化遗产保护等。

### 1.4 培养目标

培养具有曲艺表演艺术的专业理论和专业技能，能够从事曲艺类表演、创作、教学等工作，具有非物质文化遗产保护传承推广和弘扬优秀传统文化能力的高素质专门人才。

## 模块六：趣味知识/揭秘卡片

### 揭秘1：全国本科只有3所学校开这个专业

曲艺专业是全国开设院校最少的本科专业之一。截至2025年，全国仅有**中央戏剧学院、辽宁科技大学、山东艺术学院**3所高校开设曲艺本科专业[来源：大学生必备网，2025]。比很多小语种专业还少。

### 揭秘2：山东艺术学院的曲艺专业比多数985历史都长

山东艺术学院曲艺办学始于**1978年**，至今已超过45年历史[来源：百度百科/百度搜索聚合]。在全国曲艺教育领域积淀最深。

### 揭秘3：一个专业的非遗覆盖率94%

在快手平台上，国家级非遗传统曲艺类项目的覆盖率达到**94%**[来源：快手非遗生态报告，2025]，几乎"曲曲有传承人，艺艺有线上视频"。

### 揭秘4：研究生目录2022年才独立设置

"戏曲与曲艺"作为独立专业学位类别（代码1355）是**2022年**才首次纳入《研究生教育学科专业目录》的[来源：百度搜索聚合，2025]。在此之前，曲艺研究生只能挂靠在"音乐与舞蹈学"或其他学科下。

### 揭秘5：300+曲艺团，编制却难拿

全国专业曲艺表演团体超过300个[来源：豆丁网行业报告，2025]，但这些院团编制考试竞争极度激烈。很多院团每年只招1-2人，甚至"零招聘"。

### 揭秘6：银发+青年双代际传承

快手数据显示，曲艺非遗传承呈现"银发创作者+18-23岁年轻用户"双向活跃的独特格局——50岁以上创作者用短视频延续传统技艺，年轻用户积极参与互动[来源：快手2025非遗生态报告]。
