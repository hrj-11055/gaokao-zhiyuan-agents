## 模块三：院校分档与定位

### 3.1 院校金字塔

> 注：该专业2025年首次招生，目前仅有2所高校获批开设，分档意义有限。

**S 档（王者级）**：暂无（专业尚未有学科评估或长期培养积累）

**A 档（骨干级）**：重庆医科大学（医学底蕴深厚，临床医学实力强，附属医院资源丰富，地处直辖市医保体系较完善）

**B 档（特色/潜力级）**：黑龙江中医药大学（中医药特色，中西医结合医保领域有差异化优势）

**C 档（一般院校）**：暂无（后续获批开设的普通本科院校可归入此档）

> 预判：随着教育部引导性专业推广，预计2026–2028年将有更多高校（特别是医学院校和综合性大学）开设该专业，届时院校分档将更具参考价值。

### 3.2 选校建议一句话

该专业首选医学院校（医学底蕴+附属医院实习资源），其次综合性大学（公共管理学科实力），普通院校暂不建议。

## 模块五：职业路径图

### 路径一：体制内（医保局/社保中心）

`本科毕业` → `参加公务员/事业单位考试` → `进入省/市/区级医保局` → **`从事医保基金监管、政策制定与评估工作`**

典型薪酬范围：8–15 万/年（视地区和级别）    达成概率：低（公考竞争激烈，岗位数量有限）

### 路径二：商业健康险（保险公司）

`本科/硕士毕业` → `进入商业保险公司健康险部门` → `成长为核保/理赔/产品开发专家` → **`成为健康险产品经理或精算师`**

典型薪酬范围：10–30 万/年（5年后）    达成概率：中（行业需求增长，但竞争同样激烈）

### 路径三：医院医保办/运营管理

`本科毕业` → `进入医院医保办公室` → `负责医保合规与费用审核` → **`成长为医院运营管理/医保管理骨干`**

典型薪酬范围：8–18 万/年    达成概率：中（三甲医院竞争大，基层医院较容易）

## 模块六："反差与揭秘"趣味卡片

### 6.1 刻板印象 vs 现实

**你以为的 健康与医疗保障 学生**：在医院穿着白大褂给人看病开药，或者坐在保险公司柜台卖保险。

**真实的 健康与医疗保障 学生**：一手翻《临床医学概论》背解剖学术语，一手啃《卫生经济学》和《计量经济学》跑回归模型，还要在"保障政策角色扮演磋商会"上模拟医保谈判。四年下来既不是医生也不是保险业务员，而是一个懂医学常识、会政策分析、能用数据说话的"医保系统齿轮"。

### 6.2 "一句话入坑测试"

**场景**：你看到新闻说"某地医保局谈判把一款抗癌药从每月5万砍到每月5千"，你的第一反应是：

- **A.** "哇，患者终于能吃得起药了！" → 你更关注医疗本身，可能更适合临床医学或药学
- **B.** "这个谈判策略是怎么设计的？医保基金能撑住吗？替代方案有哪些？" → 你已经开始用医保管理思维看问题了，和这个专业高度匹配

**匹配指数**：选 B → ★★★★★（5 星，高度匹配）    选 A → ★★☆☆☆（2 星，可能需要重新考虑）

### 7.2 一句话情景测试

**问题**：朋友向你抱怨"看个感冒花了800块，医保才报销200"，你会怎么说？

- **A.** "确实太贵了，医院太黑了" → 你倾向于情绪化判断，不太适合需要客观分析的职业
- **B.** "800块里哪些是医保目录内、哪些是自费项目？你的起付线到了吗？如果觉得不合理可以申请医保审核" → 你天然具备医保管理的分析框架，这个专业很适合你

根据选项给出用户与本专业的**匹配指数**：选 B → ★★★★★（5 星）    选 A → ★★☆☆☆（2 星）
