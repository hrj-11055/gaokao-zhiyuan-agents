# 大学深度研究待办任务

更新日期：2026-05-12

## 任务目标

为本批次 174 所本科院校分别生成一篇 Markdown 深度研究报告。

每所学校输出 1 个文件：

```text
{大学名称}.md
```

示例：

```text
重庆大学.md
南开大学.md
```

## 交付要求

- 文件格式：Markdown
- 文件命名：直接使用学校中文名，例如 `重庆大学.md`
- 单篇字数：目标 8000 字以上，最低不得低于 5000 字
- 数据原则：必须搜索真实来源；找不到的数据写「未检索到」
- 禁止事项：严禁编造录取分数、就业率、薪酬、学科评估、排名等数据
- 章节结构：每篇必须包含 8 个章节

## 每篇报告固定章节

1. 学术实力
2. 录取与生源
3. 毕业生出路
4. 区位与产业
5. 国际化
6. 校园生态
7. 风险提示
8. 总结评价

## 最低内容要求

| 章节 | 最低要求 |
|---|---|
| 学术实力 | 列出王牌学科、A 类学科数量或学科评估结果 |
| 录取与生源 | 至少覆盖 3 个省份的近年分数线或位次趋势 |
| 毕业生出路 | 深造率或就业率 + 代表性去向单位或院校 |
| 区位与产业 | 所在城市经济特征 + 与学校优势学科的关联 |
| 国际化 | 合作项目或交换机会；无明确资料则写未检索到 |
| 校园生态 | 转专业政策 + 宿舍/食堂简评 |
| 风险提示 | 至少提及 1 项已知风险或注意事项 |
| 总结评价 | 六维打分表 + 横向对比 1 所院校 + 报考建议 |

## 质量验收标准

总分 5 分，4.0 分及以上为合格。

### 1. 准确性，40%，2.0 分

- 所有关键数据必须来自可检索的真实来源
- 包括录取分数线、就业率、深造率、薪酬、学科评估等级等
- 发现编造数据，一票否决，报告需重做
- 找不到的数据必须写「未检索到」

### 2. 内容完整性，30%，1.5 分

- 必须包含 8 个固定章节
- 每章必须有实质分析，不能只有两三行数据罗列
- 缺少任意章节扣 0.2 分
- 章节明显空洞扣 0.1 分

### 3. 实用性，20%，1.0 分

- 有明确分析和观点
- 对高考志愿填报有参考价值
- 能说明适合哪些考生、不适合哪些考生
- 语言流畅，逻辑清晰

### 4. 字数达标，10%，0.5 分

- 5000 字以上：满分
- 3000-4999 字：0.3 分
- 3000 字以下：0 分

## 执行流程建议

1. 从下方学校清单中选择 1 所学校。
2. 打开 `大学深度研究-运行提示词.md`。
3. 将提示词中的 `[大学名称：XXX]` 替换为实际学校名称。
4. 如无特定关注专业，将 `[专业1、专业2 等，无则填"无特定关注"]` 替换为「无特定关注」。
5. 使用具备联网搜索能力的 AI 工具运行提示词。
6. 将生成内容保存为 `{大学名称}.md`。
7. 按质量验收标准检查：
   - 是否 5000 字以上
   - 是否有 8 个章节
   - 是否至少覆盖 3 个省份录取数据
   - 是否有就业或深造数据
   - 是否没有编造数据
   - 找不到的数据是否写了「未检索到」
8. 完成后在本清单中将学校状态改为已完成。
