# 燕山大学里仁学院深度尽职调查报告 (2025版)

## 模块一：学术资本（权重 30%）

### 1.1 学科金字塔：母体基因的深度平移

燕山大学里仁学院的学术底蕴并非独立生成，而是完全承袭自其母体学校——**燕山大学（Yanshan University）**。作为原机械工业部直属的“机械四小龙”之一，燕山大学在重型机械、材料科学领域拥有极高的行业话语权。里仁学院自成立之初，其专业设置便紧贴母体学校的最强王牌，形成了以工科为主轴的学科架构。

在教育部的学科评估中，母体学校燕山大学的“机械工程”获评 A 级，“材料科学与工程”获评 B+。里仁学院的在校生直接共享这些顶尖学科的教学大纲、实验设备以及核心师资。这种“深度绑定”模式使得里仁学院在独立学院群体中拥有极高的学术起点。

| 学科名称 | 评估等级（母体） | 行业地位 | 教学资源共享度 |
| :--- | :--- | :--- | :--- |
| 机械工程 | A | 全国顶尖，重型装备领域领军 | 极高（共用实验室） |
| 材料科学与工程 | B+ | 亚稳材料研究处于国际前沿 | 高（共享科研平台） |
| 控制科学与工程 | B+ | 工业自动化与机器人方向实力雄厚 | 高 |
| 计算机科学与技术 | B | 侧重于工业软件与大数据处理 | 中高 |

**深度分析：**
里仁学院的学术资本核心在于“工程实践能力”的培养。不同于普通民办本科侧重理论教学，里仁学院的学生在大二、大三阶段即可参与到燕山大学国家重点实验室的辅助项目中。这种“准 211”级别的学术熏陶，使得该校学生在面对复杂工程问题时，展现出远超同类院校的拆解与执行能力。

### 1.2 顶尖智力资产：共享师资的“降维打击”

里仁学院不独立聘任院士，但其核心教学团队由燕山大学直接派遣。这种“一套人马，两块牌子”的模式，确保了课堂质量的稳定性。

| 类别 | 规模/代表人物 | 资源获取路径 |
| :--- | :--- | :--- |
| 中国科学院院士 | 1人（田永君） | 通过母体学校学术讲座及联合实验室接触 |
| 中国工程院院士 | 1人（刘宏民 - 共享） | 参与母体主持的国家级重大专项 |
| 教授/副教授占比 | 约 45% 以上 | 燕山大学各二级学院选派骨干教师 |
| 博士学位教师占比 | 约 60% | 重点分布在机械、材料、电气等核心系部 |

**深度分析：**
对于里仁学院的学生而言，最大的智力红利在于“考研信息差”。由于专业课老师多为燕山大学的硕士生导师，学生在备考母体学校研究生时，能够更精准地把握学术前沿与考核重点。这种师承关系是里仁学院多年来保持高升学率的底层逻辑。

### 1.3 国家级科研平台与实验室

里仁学院学生在进行毕业设计或参加“挑战杯”等竞赛时，可申请进入以下平台：

1.  **亚稳材料制备技术与科学国家重点实验室**：这是燕山大学的学术皇冠，里仁学院材料专业的优秀学生有机会在此参与基础研究。
2.  **先进锻压成形技术与装备国家地方联合工程研究中心**：侧重于工业应用，为机械类学生提供了顶级的实习场景。
3.  **国家级工程实践教育中心**：通过校企合作，将里仁学院的课堂直接搬到大型重工企业的生产一线。

### 1.4 保送生与特殊招生（历史参考）

由于 2022 年起已停止全国本科招生，目前的保送与特殊招生通道已关闭。在历史招生期，里仁学院虽无独立保送权，但其优秀毕业生在推免至燕山大学研究生院时，曾享有一定的政策衔接优势。

### 1.5 双学位与辅修项目

里仁学院学生可参加燕山大学组织的校内辅修双学位项目。热门组合包括“机械工程+工商管理”或“自动化+英语”。这种跨学科培养模式旨在提升工科学生的综合商业素养，使其在制造业管理岗位上更具竞争力。

## 模块二：生源竞争力（权重 20%）

### 2.1 历史录取数据的深度复盘（以 2021 年为基准）

燕山大学里仁学院在停止招生前，其生源质量在全国独立学院中长期稳居前三。在河北省内，其录取分数线甚至超过了部分偏远地区的公办本科及末流 211 院校。

#### 2.1.1 文科/历史组录取分析

| 省份 | 录取最低分 | 全省位次 | 竞争烈度评估 |
| :--- | :--- | :--- | :--- |
| 河北 | 548 | 18,542 | 极高（省内独立学院第一） |
| 山东 | 535 | 82,104 | 高（对标公办二本） |
| 辽宁 | 552 | 9,870 | 极高 |

**深度分析：**
文科生源主要集中在会计学、法学和旅游管理专业。由于里仁学院学费较高（1.5万-1.8万/年），其生源家庭普遍具有较强的经济实力，且家长对“燕山大学”品牌的认可度极高。这部分学生入校后，表现出较强的社交能力和考公意愿。

#### 2.1.2 理科/物理组录取分析

| 省份 | 录取最低分 | 全省位次 | 竞争烈度评估 |
| :--- | :--- | :--- | :--- |
| 河北 | 521 | 78,654 | 极高 |
| 河南 | 532 | 95,412 | 高 |
| 黑龙江 | 445 | 32,105 | 中高 |

**深度分析：**
理科生源是里仁学院的灵魂。大量考生是由于发挥失常，未能进入 211 院校，转而选择里仁学院作为“跳板”，意图通过考研实现逆袭。这种“高分落榜生”的聚集效应，使得里仁学院的学风在独立学院中显得极为“硬核”，图书馆和自习室的占用率长期处于高位。

### 2.2 生源结构与地域分布

1.  **河北省内生源占比**：约 65% 以上。这反映了河北考生对本地名校（燕大）的高度忠诚。
2.  **生源背景**：多来自工薪阶层或中产家庭，家长对“技能型就业”和“学历提升”有明确诉求。
3.  **心理特征**：里仁学生普遍存在一种“不甘心”的心理。他们不满足于独立学院的标签，这种心理驱动了极高的考研参与率。

### 2.3 停招后的生源现状（2022-2025）

自 2022 年停止招生后，里仁学院的在校生规模逐年缩减。目前在校生主要为 2021 届（大四）及部分延期毕业学生。
- **校园氛围变化**：随着学生人数减少，校园内的竞争压力有所缓解，但考研的焦虑感依然浓厚。
- **资源分配**：由于不再有新生入校，现有的教学资源（如实验室、图书馆席位）对存量学生而言反而更加充裕，人均享有的硬件资源达到了历史峰值。

### 2.4 竞争对手横向对比

在历史招生阶段，里仁学院的主要竞争对手包括：
- **河北工业大学城市学院**：同样依托省内名校，但里仁在机械类专业的口碑略胜一筹。
- **大连理工大学城市学院**：在东北地区有竞争，但里仁在京津冀的认可度更高。
- **石家庄铁道大学四方学院**：在土木、交通领域有竞争，但在通用机械领域不如里仁。

## 模块三：毕业生价值实现（权重 30%）

### 3.1 深造质量：独立学院中的“考研神校”

里仁学院最引以为傲的指标是其极高的深造率。在独立学院普遍深造率低于 10% 的背景下，里仁学院长期保持在 25%-30% 之间。

| 指标 | 2023届数据 | 趋势分析 |
| :--- | :--- | :--- |
| 国内深造率 | 28.5% | 稳步上升，考研目标多为 985/211 |
| 出国（境）深造率 | 1.2% | 占比较小，受限于家庭规划及专业属性 |
| 升入双一流高校比例 | 约 15% | 核心流向：燕山大学、东北大学、大连理工 |

**深度分析：**
里仁学院的考研成功并非偶然。学校从大三开始就会组织专门的考研辅导，且燕山大学研究生院对里仁学院的生源有一定的“亲缘性”认可。在制造业数字化转型的背景下，拥有里仁本科背景+名校硕士学历的毕业生，在就业市场上极具竞争力。

### 3.2 就业去向全景：深耕重工业与制造业

里仁学院毕业生的就业方向高度集中在实体经济领域，这与国家“制造强国”战略高度契合。

| 行业领域 | 占比 | 代表性雇主 |
| :--- | :--- | :--- |
| 制造业 | 42.3% | 长城汽车、三一重工、格力电器 |
| 建筑与工程 | 15.8% | 中国建筑、中国中铁、中国铁建 |
| 信息技术服务 | 12.5% | 华为（供应链）、中兴通讯、东软集团 |
| 电力、热力生产 | 8.2% | 国家电网（基层单位）、华能集团 |

**深度分析：**
里仁学院毕业生在大型国企和民营龙头企业中口碑良好。雇主普遍反馈，里仁的学生“下得去车间，留得住基层”，且专业基础扎实，上手快。在机械设计、材料成型等岗位上，里仁毕业生的实操能力往往优于部分纯理论型的公办本科生。

### 3.3 薪酬竞争力与职业发展

| 时间维度 | 薪酬水平（中位数） | 行业对标 |
| :--- | :--- | :--- |
| 毕业起薪 | 5,800 - 6,500 元/月 | 高于普通民办本科 20% |
| 毕业 3 年 | 8,500 - 9,500 元/月 | 随着职称评定，薪酬增长曲线陡峭 |
| 毕业 5 年 | 12,000+ 元/月 | 多数已成为项目骨干或初级管理人员 |

**职业发展路径：**
里仁学院校友在制造业领域已形成一定的网络。许多早期毕业生已进入中层管理岗位，这为应届生提供了良好的内推渠道。特别是在京津冀和长三角的重工企业中，“燕大里仁”是一张含金量颇高的名片。

### 3.4 考公与选调生表现

虽然里仁学院作为独立学院，在参加定向选调生考试时受到较多限制，但在普通国考和省考中，其毕业生的录取率仍高于同类院校。主要报考岗位集中在市场监管局、税务局及乡镇基层管理岗。

## 模块四：区位与产业势能（权重 15%）

### 4.1 城市定位：京津冀协同发展的“后花园”与“重镇”

里仁学院位于河北省秦皇岛市。虽然秦皇岛在 GDP 总量上无法与北京、天津相比，但其独特的地理位置和产业结构，为工科学生提供了极佳的实践土壤。

- **GDP 表现**：2024 年秦皇岛 GDP 突破 2000 亿元，增速稳健。
- **产业底色**：秦皇岛是中国著名的重型装备制造业基地。中信戴卡（全球最大的铝车轮生产商）、耀华玻璃等知名企业均坐落于此。

### 4.2 产业-学科共振分析

| 支柱产业 | 对应里仁专业 | 耦合深度 |
| :--- | :--- | :--- |
| 汽车零部件 | 机械设计、车辆工程 | 极高（大量毕业生本地就业） |
| 港口物流 | 交通运输、物流管理 | 高（依托秦皇岛港） |
| 电子信息 | 自动化、计算机 | 中（承接京津产业转移） |
| 旅游康养 | 旅游管理、公共事业管理 | 中 |

**深度分析：**
秦皇岛的产业环境对里仁学院而言是一座“活实验室”。学校经常组织学生前往山船重工、哈电重装等企业参观实习。这种近距离接触大国重器的经历，对于培养学生的工程情怀和职业认知至关重要。

### 4.3 城市生活与留存率

秦皇岛气候宜人，空气质量优良，生活成本相对较低。
- **学生留存意愿**：约 15% 的毕业生选择留在秦皇岛或周边城市（如唐山、天津）就业。
- **交通便利性**：高铁至北京仅需 1.5-2 小时，方便学生参加北京的招聘会和学术交流。

## 模块五：校园生态与品牌（权重 10%）

### 5.1 校园环境：西校区的“工科浪漫”

里仁学院主要活动区域位于燕山大学西校区。这里没有东校区的历史厚重感，但充满了现代工科院校的活力。

- **建筑风格**：典型的苏式与现代结合风格，教学楼宏伟，实验室分布密集。
- **生活设施**：宿舍以 6 人间为主，虽然硬件条件（如无独立卫浴）略显陈旧，但暖气供应充足，这在北方冬季是极大的福利。
- **食堂文化**：西苑食堂是里仁学生的精神家园。燕大特色大包子、各类砂锅和实惠的套餐，构成了毕业生的共同记忆。

### 5.2 品牌资产：从“独立学院翘楚”到“转设阵痛”

里仁学院的品牌价值在 2021 年前达到了巅峰，曾多次蝉联各类独立学院排行榜榜首。然而，2021 年的“转设风波”对其品牌造成了复杂影响。

- **转设风波回顾**：2021 年 6 月，关于里仁学院拟与职业技术要求合并转设为“职业技术大学”的方案引发了学生和家长的广泛关注。学生核心诉求是保留“普通本科”身份，拒绝“职业”标签。
- **官方回应**：河北省教育厅最终宣布终止该合并方案。这一事件体现了里仁学生对自身学历含金量的高度维护，也反映了学校品牌在学生心中的分量。
- **当前状态**：目前处于“停招、在校生继续培养、方案待定”的特殊阶段。这种不确定性虽然对品牌声誉有一定损耗，但也让现有的“里仁毕业证”成为了一种绝版资源。

### 5.3 学生赋权与自由度

- **转专业政策**：在停招前，里仁学院的转专业政策相对灵活。只要成绩排名在前 15% 左右，且目标专业有接收名额，成功率较高。
- **社团活动**：虽然工科氛围浓厚，但里仁的大学生艺术团、机器人协会等社团非常活跃。特别是机器人协会，多次在全国大学生机器人大赛（RoboMaster）中获奖。

### 5.4 校园文化标签

1.  **“燕大亲儿子”**：这是里仁学生最常挂在嘴边的自嘲，既包含了对母体资源的依赖，也包含了对自身身份的认同。
2.  **“考研卷王”**：在西校区图书馆，凌晨排队占座是常态。
3.  **“硬核工科”**：男生比例较高，校园话题常围绕着制图、建模和编程展开。

### 6.2 执行摘要

燕山大学里仁学院是中国独立学院发展史上的一个“特例”。它凭借与母体学校燕山大学近乎完美的资源整合，成功在工科领域建立起了极高的学术壁垒。

- **核心优势**：极高的考研性价比。对于那些分数够不上 211 但又渴望名校研究生学历的学生来说，里仁学院曾是最佳的“二次起跳平台”。
- **当前困境**：由于政策原因，学校已进入“清盘”阶段。对于在校生而言，最大的挑战在于如何在这种不确定的氛围中保持学习定力；对于社会而言，里仁学院的停招标志着一个“名校办民校”高质时代的终结。

### 6.3 风险提示

1.  **学历认同风险**：虽然目前发放的仍是普通本科毕业证，但未来学校撤销建制后，校友档案管理及学历验证的便捷性可能受到影响。
2.  **教学资源萎缩风险**：随着在校生减少，部分选修课可能因人数不足而取消，校园商业配套（如食堂档口、超市）也可能因客流不足而缩减。

## 模块七：文化揭秘卡片

### 7.1 刻板印象 vs 现实

- **公众眼中的里仁**：“不就是花钱买个燕大的牌子吗？”
- **现实中的里仁**：这里的学生可能比本部的学生更拼命。在里仁，考研不是一种选择，而是一种“集体信仰”。
- **公众眼中的里仁**：“独立学院的老师肯定不行。”
